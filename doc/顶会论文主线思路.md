# 顶会论文主线思路：在 SGS + EKF 之上，还缺什么

> 2026-11-20。依据：当前代码（SGS + EKF + critic 时间通道 + T1 动作归一化）、本地论文库，以及这次检索到的 2025–2026 年相关工作。
> 前提不变：Actor 观测只用真机可得的量；特权信息只进 critic、奖励和课程。
> 新颖性判断都基于**有限的检索**，投稿前必须为每个创新点做一次系统检索（见 §8）。

## 0. 一页结论

**现在的工作还不够一篇顶会，原因是：SGS 和 EKF 都是别人的组件。** 审稿人会把“DQ-Net + SGS + EKF”读成工程集成。顶会需要三样东西：一个**别人没讲清楚的问题洞察**、一个**由洞察推出的新原理**、以及**能证明原理的实验**。

**推荐主线 A：“在哪里、什么时候和物体相遇”——用学到的自身时间可达性做拦截决策。**

- **洞察。** 动态抓取和“接球”不一样。接球时，相遇时间由物理决定（球什么时候落地）。动态抓取时，**相遇的时间和地点是机器人自己要做的决策**。现有方法要么追着物体的当前位置跑（DQ-Net 的接近奖励就是这样，也是本代码的现状），要么把时间当作外部给定的量（2026 年的四足接球工作）。
- **新原理。** 学一个机器人的**时间距离函数** `T(s, g)`：从当前状态把末端送到位姿 `g` 最少需要多少时间。只用本体感知加目标位姿，真机可用。它和 EKF 的物体预测合成**拦截裕度** `M = max_{i,h} [h − T(s, ĝ_i(t+h))]`。这一个量同时驱动三处：
  - 表征：时空抓取 token，同时回答“抓哪个、什么时候抓”；
  - 奖励：势函数塑形，取代追踪式的接近奖励；
  - 课程：把 SGS 从静态任务推广到动态任务，区分“难”和“不可能”。
- **新颖性。** 检索到的 quasimetric / 时间距离 RL（QRL、TMD、MQE）都只处理**静态目标**；四足接球的工作没有学习到达时间；DYNAMIT 用解析的末端行程时间、固定基座、零样本规划；SGS 和 OmniReset 只在静态任务上验证。见 §2。

**两条备选主线：**

- **B：多假设预测与“留后路”的拦截。** 目标运动会突然改变时，用 IMM 给出多个预测假设，策略学会对多种未来都保持可达。它可以作为 A 的第二贡献，也可以独立成文。
- **C：显式承诺的混合动作。** 用离散动作选择抓取 token，配合连续控制，取代 GFM 现在“对候选位姿做加权平均”的软注意力。工程量小，适合作为 A 的表征子模块。

**先做什么。** 先过三道诊断关卡（§3.6），不需要新模型，用现有 checkpoint 就能做。关卡不通过，就换主线，不要直接投入大工程。T1–T3（见 `教师训练改进思路.md`）要先做完，否则基线太弱，所有增益都不可信。

## 2. 文献地图：最相关的 2025–2026 年工作和空白

| 工作 | 做了什么 | 和本文的差别 / 空白 |
|---|---|---|
| **DQ-Net / DQ-Bench**（AAAI 2026） | 腿足机械臂动态抓取的基准和教师-学生框架；教师用特权位姿和速度 | 抓取选择只看**当前**位姿；接近奖励追的是物体当前位置 |
| **DeViGrasp**（2026，同平台 B1+Z1） | 感知退化下的移动抓取；可靠性感知的时序记忆 | 关注感知，不处理“何时相遇” |
| **Spatiotemporal Agility**（arXiv 2608.06907，浙大 / LimX） | Go2 用背上的篮子接抛来的网球；Kalman 滤波预测落点和剩余时间 `t_go`，策略以“相对位置 + 归一化剩余时间”为条件；时间门控奖励 `M(t_go, D) = 1/D · I(t_go ≤ D)` | **相遇时间由抛物线物理决定**，落点就是拦截点，没有学习到达时间（据阅读，部分内容来自摘要，需核对原文）；可以作为“时间条件化”基线 |
| **DYNAMIT**（MERL，2026） | 传送带抓放，零样本；可达性感知的规划器，用末端行程时间决定何时何地抓 | 规划式方法，行程时间是解析估计；固定基座，不涉及全身 RL |
| **KARL**（IROS 2025） | 在感知和 RL 之间加 Kalman 滤波，处理遮挡 | 解决“看不见”，不解决“何时相遇” |
| **GAP-RL**（RA-L） | 把抓取位姿编码成高斯点，用于动态抓取 RL | 第三方摘要指出它没有使用多帧时间信息 |
| **DynamicVLA / DOM、PUMA / DOMINO**（2026） | 动态操作的 VLA；PUMA 用光流历史加 world query 预测未来物体状态 | 模仿学习路线，固定臂；成功率仍低（DOM 上约 47%，DOMINO 上约 17–21%） |
| **QRL / TMD / MQE**（2023–2025） | 用 quasimetric 结构学习**最优时间距离**，用于目标条件 RL | 检索中没有找到处理**移动目标**的工作——这正是本文的空白 |
| **SGS**（本地 `SGS.pdf`）、**OmniReset**（ICLR 2026） | 大规模 RL 的初态分布：SGS 按成功率采样，OmniReset 用多样化重置 | 都是**静态**任务（OmniReset 明确说目标物体不随环境运动）；成功率为 0 时无法区分“难”和“不可能” |
| **Learning Dynamic Pick-and-Place for a Legged Manipulator**（RA-L 2026，KAIST） | 腿足机械臂抓放，分阶段奖励，LSTM 估计质量；真机物体位姿用 Vicon | 物体静止；没有引用 DQ-Net |

**结论：** “腿足全身 RL + 移动物体 + 学习的时间可达性 + 动态任务课程”这个组合，在检索范围内是空白。最接近的是 Spatiotemporal Agility，但它的时间由物理决定、不由策略决定，而本文的关键恰恰是**时间是决策变量**。

## 3. 主线 A（推荐）：用学到的时间可达性做拦截

### 3.1 问题洞察：为什么“追”不够

简化模型：机器人初始离物体 d₀ = 2 m，底座最大速度 V = 0.45 m/s（代码中 vx 的截断上限）；物体以 u 的速度沿垂直于初始视线的方向匀速运动（Level02 的直线模式）。忽略手臂伸展和转向限制：

| 物体速度 u | 纯追踪（始终朝向物体当前位置）的捕获时间 `d₀V/(V²−u²)` | 恒定方位角拦截的捕获时间 `d₀/√(V²−u²)` | 追踪 / 拦截 |
|---|---|---|---|
| 0.15 m/s（Level02 下限） | 5.0 s | 4.7 s | 1.06 |
| 0.30 m/s（Level02 上限） | 8.0 s | 6.0 s | 1.34 |
| 0.40 m/s（外推） | 21.2 s | 9.7 s | 2.18 |

回合时限约 15 s（100 步 × 约 0.15 s）。**物体越快，追踪的代价增长越快**：u 接近 V 时，追踪的捕获时间趋于发散，而拦截时间增长得慢得多。圆周运动和转向约束只会让差距更大。

这就是论文的动机图。但它是理论推导，**现有教师是否真的在“追”，需要关卡 D1 来验证**（§3.6）。

现有代码中，“追”的倾向来自两处：

- `approaching` 和 `base_approaching` 两个奖励都对准物体的**当前**位置（[`reward_vec_task.py:11`](../DQ_high-level/envs/reward_vec_task.py#L11)、[`:127`](../DQ_high-level/envs/reward_vec_task.py#L127)）；
- GFM 的注意力只看当前时刻的 30 个抓取候选（[`b1z1_pickmulti.py:812`](../DQ_high-level/envs/b1z1_pickmulti.py#L812)）。EKF 的未来位姿只进了 Query，**没有变成候选**。

### 3.2 方法：一个量，三处使用

**(1) 自身时间距离 `T_θ(s, g)`。**

- **含义**：从当前机器人状态 `s`（低层观测历史、当前末端目标）出发，把末端送到位姿 `g` 所需的最少时间。`g` 表达在当前时刻冻结的臂基坐标系中。
- **数据**：来自策略自己的 rollout，属于事后标注——`(s_t, 末端在 t+k 时刻的实际位姿)` 构成一个样本，标签是实际耗时 `k·Δt`，它是最短时间的一个**上界**。
- **学法**：quasimetric 结构（满足三角不等式，例如 MRN / IQE）加多步目标（MQE 风格），或者用低分位的 expectile 回归去逼近下包络。物理下界做兜底：`T ≥ 距离 / 最大速度`。
- **为什么用 quasimetric**：TMD 和 MQE 证明，这种结构能学到**最优**时间距离，并且避免动态规划的误差累积。本文把它从静态目标推广到“与预测结合的移动目标”。
- **部署**：输入只有本体感知和目标位姿，真机可用；训练时 `T` 的参数不进 PPO 的计算图，用独立的优化器训练，并维护一份 EMA 副本，供奖励和课程使用。

**(2) 拦截裕度。**

```text
M(s_t) = max over (i ∈ 30 个抓取候选, h ∈ {0, 0.3, …, 4.8 s 且 h ≤ 剩余时间})  [ h − T(s_t, ĝ_i(t+h)) ]
```

- 进策略的 `ĝ` 用 EKF 预测（真机可得）；进奖励和课程的用仿真真值的未来（特权，只在训练中使用）。
- 计算量：每个环境每步 30 × 16 = 480 次小 MLP 推理；8192 个环境约 390 万次，在 GPU 上是毫秒级。

**(3) 三处使用：**

| 环节 | 做法 | 替换了什么 |
|---|---|---|
| **表征** | 30 个候选 × H 个时刻 = 时空 token；每个 token 带上 6D 位姿、`h`、`m_ih = h − T(·)`、EKF 不确定性。注意力（或主线 C 的显式选择）回答“抓哪个、什么时候抓” | 只看当前候选的 GFM |
| **奖励** | 势函数塑形 `F = γΦ(s′) − Φ(s)`，`Φ = κ·clip(M, −c, c)/c`，物体抬起后关闭 | 追踪式的 `approaching` / `base_approaching` |
| **课程** | 动态 SGS：用初态裕度 `M₀(c)` 给每个配置一个可行性先验，区分“难”（`M₀ ≳ 0`）和“不可能”（`M₀ ≪ 0`）；在 `M₀ ≈ δ` 附近变异生成前沿配置，`δ` 随训练逐渐变小 | SGS 只按成功率采样，固定配置库 |

### 3.3 可以写成命题的部分

| 命题 | 内容 | 说明 |
|---|---|---|
| P1 必要性 | 若 `T` 是最短时间的下界，且预测准确，那么成功的回合在接触之前每一时刻都满足 `M ≥ 0` | 说明 `M` 是有意义的可行性度量；`M ≥ 0` 是必要条件，**不是充分条件**（抓取失败另算） |
| P2 塑形不变性 | `Φ` 固定时，势函数塑形不改变最优策略（Ng et al. 1999） | `T` 在训练中会变化，所以要用 EMA 或分阶段冻结，并在文中说清楚 |
| P3 分解 | `M` 把“物体会去哪”（EKF）和“自己多快能到”（`T`）分开；物体运动模式改变时，`T` 不需要重新训练 | 可检验：在 Level02 上训练 `T`，到 Level01 / 03 / 04 上测试 |
| P4 课程标定 | 配置的成功概率随 `M₀` 单调递增 | 用 AUC 和校准曲线检验（关卡 D3） |

### 3.4 新颖性对照

| 组成部分 | 最接近的工作 | 区别 |
|---|---|---|
| 学到的时间距离用于移动目标 | QRL / TMD / MQE（静态目标）；DYNAMIT（解析行程时间） | 和预测结合；全身腿足系统；在 RL 回路里用 |
| “何时相遇”作为决策 | Spatiotemporal Agility（时间由物理给定） | 时间从候选里选，并且受自身可达性约束 |
| 时空抓取 token | GFM（DQ-Net / DeViGrasp）、GAP-RL | 加入时间维和可行性特征 |
| 裕度势函数 | 时间门控奖励（Spatiotemporal Agility）、距离塑形 | 不需要事先知道相遇时间；不改变最优策略 |
| 动态任务课程 | SGS、OmniReset（静态） | 有可行性先验，能区分“不可能”，会生成配置 |

### 3.5 实验设计

**基准**

- DQ-Bench Level01–05（不同运动模式），物体速度从 0.15 外推到 0.4 m/s；
- 多物体（YCB 30 个），台面高度变化；
- 真机：B1 + Z1，6D 位姿检测（见 `直接部署教师_改进思路.md`）。

**基线**

| 组 | 内容 |
|---|---|
| B0 | DQ-Net 教师（论文原始设置） |
| B1 | 当前 SGS + EKF 教师，加 T1–T3 修正 |
| B2 | 时间条件化：Spatiotemporal Agility 风格，预测拦截点 + 解析 `t_go` + 时间门控奖励 |
| B3 | 解析可达性：DYNAMIT 风格，`T = 距离 / 最大速度` |
| B4 | 距离势函数塑形 |
| B5 | OmniReset 风格的均匀多样化重置；对照原 SGS |

**消融**

- 表征、奖励、课程三项各开 / 关，2³ 析因，报告主效应和交互效应；

- 成功率、成功用时；

- `M₀` 的校准曲线；计算开销。

2. 典型回合的 `M(t)` 曲线和失败构成；

### 3.6 先过三道关（不需要新模型）

| 关卡 | 做法 | 通过 | 不通过 |
|---|---|---|---|
| **D1 追踪诊断** | 用现有 checkpoint 统计接近阶段的视线角速率、底座朝向和视线的夹角、路径长度比 | 有明显的追踪特征，奖励环节成立 | 现有策略已经在“拦”：奖励环节变弱，故事转向表征和课程 |

## 4. 备选主线 B：多假设预测与“留后路”的拦截

**问题。** DQ-Bench 的 Level03 / 04 会随机切换速度（间隔约 40–60 步）。单一 EKF 的恒速预测在切换后会突然失效，策略要么追错方向，要么来不及修正。

**做法：**

- 用 **IMM 滤波**（interacting multiple model，机动目标跟踪的经典方法）融合匀速、匀速转弯、停止等 K 个运动模型，输出 K 组预测和各模型的概率 `π_k`；
- token 按假设展开：(候选 i, 时刻 h, 假设 k)；
- **应急裕度** `M_c = Σ_k π_k·M_k`，或者取 `min_k M_k`：让策略选一个“对多种未来都来得及”的位置，而不是押注单一预测；
- 课程：切换频率作为 SGS 配置的一维，从低到高。

**新颖性：**

- 应急规划在自动驾驶中已有研究（RACP 用多模态预测做风险感知的应急规划）；
- IMM 和 RL 的结合目前出现在跟踪领域（DIMM 用 RL 学模型融合权重）；
- 检索中**没有找到用于移动操作或抓取 RL 的工作**。

**风险。** 切换不频繁时收益不明显，必须先证明单预测教师在 Level03 / 04 上明显变差。

**最佳用法。** 作为主线 A 的第二贡献（“不确定性下的拦截裕度”），对应命题 P3 的泛化实验。

## 5. 备选主线 C：显式承诺的混合动作（适合作为 A 的表征子模块）

**问题。** GFM 用 softmax 注意力对 30 个候选的投影特征加权平均，再输出 6 维（[`predictattention.py:51`](../DQ_high-level/modules/predictattention.py#L51)）。两个相距很远的候选取平均，得到的是一个**不存在的抓取位姿**；注意力在相邻两步之间来回切换，末端目标也就跟着摆动。

**做法：**

- 动作空间改成“离散选择 token + 连续控制”，属于参数化 / 混合动作空间（H-PPO、P-DQN 一类）；
- 切换 token 要付代价（承诺），或者加一个“上一步是否选中”的标记位；
- 进阶：用 flow 策略表示多模态动作。FPO 把 flow matching 损失接进了 PPO 的裁剪目标；FPO++ 加了逐样本比率裁剪和非对称信赖域，报告在四足、人形和机械臂上比高斯 PPO 更稳。

**新颖性。** 中等：混合动作空间本身是已知方法；放在“动态抓取的何时何地选择”上，并配合承诺机制，是本文的应用创新。**建议并入 A，不单独成文。**
