# 动态接触过渡生成：研究思路与验证方案

更新：2026-11-23 · 面向 B1Z1 移动糖盒抓取教师

**核心思路：生成“仍有闭爪机会、但当前策略经常错过”的接触前驱状态，让策略通过 SGS 反复练习这些关键决策，最终提高从原始起点开始的抓取成功率。**

本文说明研究目标、方法和实验。具体模块、数据结构、代码改动与命令见 [实现方案](Dynamic_contact_transition_implementation_plan.md)，整体关系见 [交互架构图](Dynamic_contact_transition_architecture.html)。本方案尚待实现和实验验证，参数均为试验起点。

## 1. 要解决什么问题

当前 SGS 根据每个起点的最终成功率决定练习频率。它能够调整已有状态的采样比例，但无法补充库中缺少的关键状态。

动态抓取中，**位置相近的状态，可能具有完全不同的行动机会**。例如，物体同样在夹爪前方约 5 cm：

| 情况 | 相对运动 | 需要学习的决策 |
|---|---|---|
| 已同步跟随 | 末端基本跟上目标，闭合机会较宽 | 保持对准并完成闭合 |
| 正在横向擦过 | 物体即将离开夹爪，闭合机会短暂 | 及时跟踪、修正并闭合 |
| 已错过当前机会 | 眼前的闭合难以奏效 | 判断是否重新追赶或调整进入方式 |

这是解释问题的示例，尚未证明当前教师主要失败于哪一种情况。

如果只保存成功闭爪后的状态，策略主要练到抬升和持稳。**把训练起点放在闭爪决策之前，才有机会练到“如何进入接触、何时闭合”。** 本方案将这种状态称为“接触前驱状态”。

研究需要回答三个问题：

1. 当前教师是否确实经常错过动态接触机会？
2. 用接触方向和闭爪时序生成起点，是否优于普通接触覆盖或失败片段回收？
3. 局部练习是否改善从约 2 m 原始起点开始的完整任务？

## 2. SGS、CSRL 与动力学探索各负责什么

| 组成 | 本方案借鉴的作用 | 在系统中的位置 |
|---|---|---|
| SGS | 根据最终成功情况分配练习次数 | 从冻结的起点库中采样 |
| CSRL 的接触约束思想 | 按接触条件寻找有物理依据的候选 | 补充未接触、单侧接触等起点 |
| 前向动力学探索 | 通过真实动作获得相容的位置、速度和控制状态 | 生成不同的接触进入方式 |
| 本方案拟研究的机制 | 探测可执行闭爪时序，寻找策略尚未掌握的机会 | 决定生成和保留哪些接触前驱 |

**拟议贡献是“面向接触时序机会的起点生成机制”。** 接触覆盖、RRT 建库、在线状态回收和失败附近重置已有相关工作，简单组合不能自动构成新颖性。

第一版采用有限的短程前向分支即可。CSRL 提供接触条件的启发，RRT 类工作提供动力学可达性的启发；暂不要求复现通用约束求解器或完整规划树。

## 3. 三个核心概念

### 3.1 接触转换：先聚焦“形成有效闭合”

| 状态 | 含义 |
|---|---|
| F | 物体有桌面支撑，夹爪未有效触物 |
| C1 | 单侧手指接触物体，物体仍有支撑 |
| C2 | 双侧有效接触，物体在夹爪内，仍有桌面支撑 |
| L | 物体已离桌，仍处于受控夹持 |
| H | 满足项目原有的最终持稳（hold）判据 |
| U | 接触证据不足，无法可靠判断 |

**第一版研究 F／C1 → C2，随后用离桌和最终 hold 检验效果。** 允许 F 直接进入 C2，也允许失去一侧接触后重新恢复，不强制所有成功轨迹经过同一顺序。

接触标签只供仿真建库和分析使用。现有指尖净力可能来自桌面，需结合几何、夹持位置和时间连续性判断；无法确认的样本记为 U，不能直接当成无接触。

### 3.2 经验闭爪窗口：从这个状态出发，哪些闭合时机有效

对同一前驱状态，分别尝试现在闭爪、等待 1 步、2 步、3 步再闭爪，观察是否在限定时间内形成有效接触。成功的时序集合称为**经验闭爪窗口**：

$$
\widehat{\mathcal W}(x)
=
\left\{\delta:\widehat P\!\left(
\text{在 }H\text{ 步内新完成目标转换}
\mid x,\delta,\bar\pi,\eta
\right)\ge\tau\right\}.
$$

其中，$x$ 是候选状态，$\delta$ 是闭爪延迟，$\bar\pi$ 是冻结的参考策略，$\eta$ 是指定的跟踪偏置，$H$ 是探测时限，$\tau$ 是校准后的判定阈值。

这个窗口仅对应测试过的策略、动作族和环境条件：

- 成功时序可能不连续，需保存每个时序的结果。
- 全部探测失败只表示“尚未找到成功动作”，不能证明状态不可达。
- 少量重复只用于初筛，关键候选需要独立复验。
- 目标转换必须在探测后新发生；已有 C2 的状态不能算“零时刻形成 C2”。

当前高层动作间隔约为 0.14／0.16 s。因此窗口既记录步数，也记录实际时间，不能假设策略能执行任意毫秒级切换。

### 3.3 策略错过机会：有成功窗口，但自然策略没有利用

每个候选都需要一个**完全不干预动作的参考策略对照**。将它与时序探测结果比较，重点寻找：

> 某些闭爪时序能够重复成功，但当前策略自然续跑时经常失败的状态。

“没有末端偏置，但仍强制指定闭爪时刻”属于干预，不能替代自然策略对照。

这一差异只能说明存在尚未利用的机会。它是否值得练习，仍需通过训练后的完整任务成绩判断。

## 4. 方法流程：从完整轨迹到 SGS 练习

### 第一步：定位完整任务的接触瓶颈

冻结现有教师，从原始起点执行，统计：

- 是否到达可接触区域；
- 到达后是否形成有效闭合；
- 闭合后是否离桌、最终持稳；
- 失败时的相对速度、进入方向和闭爪时机。

保存关键事件前的短片段。成功轨迹以事件发生为锚点；失败轨迹以首次进入捕获区域或首次可信接触为锚点，避免候选只来自已经成功的行为。

若主要失败发生在远距离追赶或物体感知，应先调整研究重点。

### 第二步：用前向动作生成不同的接触前驱

从记录的父状态出发，通过现有九维高层控制接口执行短动作前缀，改变跟踪、横向对准或底盘配合，得到不同进入方式。

**这一层负责生成新状态。** 位置、速度、夹爪参考和历史由真实物理推进共同形成，不独立随机修改速度，也不跨接触模式直接插值整个状态。

候选可以来自完整任务轨迹，也可以来自已有预抓／近目标辅助起点。后者只证明相对辅助根可达，不能声称已从 2 m 起点到达；但也不能因当前策略尚到不了而全部删除。

### 第三步：从同一候选探测闭爪窗口

恢复第二步产生的状态，改变闭爪延迟和有限跟踪偏置，执行短分支，并与自然策略对照比较。

**这一层负责评价行动机会。** 它与“生成不同进入方式”是两个独立操作，实验中也应分别消融。

探测时须满足：

- 保存并训练的是目标转换之前的状态。
- C1 的等待阶段保持已有夹爪目标，不能主动张爪释放接触；当前接口中 a6=0 是半开，并非保持。
- 配对分支使用相同动力学参数和控制周期，避免把环境差异误判为时序效果。
- 探测分支的未来状态和动作不进入策略当前观测，EKF 只使用截至快照时刻的过去信息。

### 第四步：验证恢复，并选入冻结起点库

候选先通过物理与恢复检查，再按进入方向、速度、窗口和来源筛选。保留三类状态：

| 类别 | 作用 |
|---|---|
| 容易、可重复成功的状态 | 维持基本技能与稳定学习信号 |
| 有成功窗口但策略经常错过的状态 | 本方法重点提供的练习 |
| 物理有效、尚未找到成功动作的未知状态 | 保留探索前沿 |

不只选择最窄窗口：极窄窗口可能超出控制能力，或者由噪声、模拟器误差造成。同一源轨迹的相邻帧也要去重，避免表面容量很大、实际覆盖很小。

候选至少携带：可恢复上下文、目标事件、窗口结果与重复次数、自然策略结果、来源轨迹、策略版本和动力学身份。

### 第五步：SGS 选起点，PPO 重新练习

正式训练仍按以下分工进行：

1. SGS 选择起点。
2. 恢复该起点，当前策略重新采集 rollout。
3. PPO 使用这些新数据更新策略。
4. 正式回合结束后，以原最终 hold 结果更新 SGS。

**生成器只提供起点；策略仍通过原任务奖励学习动作。** 窗口标签不直接告诉策略正确动作，旧探测轨迹也不写入 PPO memory。局部接触成功与最终 hold 分开统计。

首版采用独立 collector 和离线冻结库。在线生成与外层收益选样等到离线效果成立后再研究。

## 5. 首版范围与必要条件

### 5.1 同容量起点库

当前 v12 共 1536 个配置，full_task、pregrasp、near_goal 各 512。建议首版仍使用 1536 个可采样起点：

| 运行时分组 | 数量 | 内容 |
|---|---:|---|
| full_task | 512 | 原始完整起点 |
| near_goal | 512 | 后段持稳练习 |
| curriculum | 512 | 128 个原 pregrasp＋384 个待比较候选 |

384 个候选可暂按“容易／策略错过／未知”分为 96／192／96，比例需要消融。候选不足时回填已验证的辅助起点并报告实际数量，不放宽恢复要求来凑数。

所有生成方法使用同样容量和辅助起点。容量比例不等于实际采样比例，还需记录 SGS 的 reset 次数和各类起点占用的 PPO 步数。

工程上采用实现方案中的**组合式 bundle**：保留旧 bank 的格式和证据，独立保存动态上下文。不要将动态状态直接加入旧静态几何 profile。

### 5.2 一个小规模探测起点

| 参数 | 建议起点 |
|---|---|
| 目标事件 | F／C1 → C2 |
| 每批待探测候选 | 32 个 |
| 闭爪延迟 | 0、1、2、3 个高层周期 |
| 跟踪偏置 | 每候选 2 种 |
| 粗探测重复 | 每组合 2 次；关键结果另做独立复验 |
| 短分支时限 | 8 个高层步，约 1.12–1.28 s |
| 额外对照 | 完全不干预的自然策略续跑 |

仅干预粗探测约为 4096 个单环境高层步，另计进入前缀、自然策略对照、恢复、复验和长续跑。这些数值是工程起点，尚未经调优。

### 5.3 恢复必须保留动态机会

现有 bank 已保存位姿和速度，但现有 reset 会清理控制与估计历史。动态状态还需恢复相容的控制参考、步态、目标运动相位、低层历史、EKF 和必要的 Actor history。

| 恢复用途 | 时间与进度处理 | 验证目标 |
|---|---|---|
| 续跑一致性检查 | 保留原任务进度与剩余时长 | 与未中断分支相比，动态机会是否仍成立 |
| 正式课程练习 | 恢复物理上下文，重新给 100 步，hold 从 0 开始 | 让各方法在相同练习时限下学习 |

先在等动力学条件下配对验证恢复，再按原训练动力学分布检查兼容性。动态接触态允许运动，不能用统一“静止等待一秒”作为有效性标准。

具体字段、EKF 时间重定位、Wrapper history、异步 reset 和 bank 校验见 [实现方案第 6–10 节](Dynamic_contact_transition_implementation_plan.md)。

## 6. 怎样证明这个方法有效

### 6.1 分别验证三个层次

| 层次 | 要回答的问题 | 证据 |
|---|---|---|
| 恢复有效 | 保存后是否仍保留原来的动态机会？ | 未中断与恢复后的配对续跑 |
| 当前可解 | 是否有可重复成功动作，当前策略能否利用？ | 窗口探测与自然策略对照 |
| 训练有用 | 练这些起点是否改善完整任务？ | 等预算训练后的原始起点评估 |

物理有效、有前向路径、当前可解和训练有用不能互相替代。候选局部成功率提高，也不自动说明完整任务改善。

### 6.2 主比较

| 组别 | 内容 | 排除的替代解释 |
|---|---|---|
| B0 | 原 v12＋SGS | 相对当前系统没有实际收益 |
| B1 | 同容量接触条件覆盖＋SGS | 收益只是因为接触状态更多 |
| B2 | 普通轨迹／失败前片段回收＋SGS | 简单回收已经足够 |
| B3 | 同预算随机前向分支＋SGS | 收益只是额外动态探索 |
| O1 | 窗口定向生成＋原 SGS | 检验本方案的额外价值 |

第一轮可先比较 B0、B1、B2、O1，再补齐 B3 等强基线。恢复修复应共享给适用对照；如果修复本身改变 v12 表现，单独报告修复后的 B0。

B2 可借鉴 ConTrack 的 reset 思想，但应标为机制迁移版，不能称为完整论文复现。

### 6.3 最关键的消融：同一候选池，不同选样信息

从同一个物理有效候选池导出同容量 bank，依次比较：

1. 只使用几何和接触模式；
2. 加入相对速度；
3. 再加入事件方向、窗口和自然策略错位；
4. 同配额下随机选择。

各组采用相同恢复协议，并尽量匹配几何范围、来源、练习时限和局部难度。不同生成器独有的状态覆盖另做分析。

**去掉动态信息，是让选择器不看这些信息；不是把状态速度清零或删除控制历史。** 后者会同时破坏物理有效性。

还应比较同一轨迹的“转换前起点”和“转换后起点”，检查收益是否确实来自练习转换决策。

### 6.4 指标、预算与训练效用

主指标使用关闭 SGS、从约 2 m 原始 Level02 起点执行的 hold_success_rate；辅助报告失败惩罚时间、首次抬升、接触到闭合、离桌到持稳和滑脱情况。原 hold 是代理判据，补充物理审计，但不悄悄更换主指标。

公平比较需要同时满足：

- 总容量、辅助起点、恢复协议及任务时限一致。
- 记录训练、建库、筛选、恢复和课程验证的全部交互及墙钟成本。
- 交代参考教师的来源；额外训练教师来建库的成本不能忽略。
- 课程校准／验证与最终测试分开。
- 用独立训练种子报告差值和置信区间；可先 3 个筛查，关键结论扩展到至少 5 个。

若需进一步测量某类起点的训练效用，可从同一检查点复制完整训练状态，与**同样继续训练了等量预算**的控制分支比较完整任务改善。当前 SGS 入口不支持训练 resume，这项诊断需要后续专用接口，首版不依赖它。

## 7. 实施顺序

阶段编号与实现方案一致。

| 阶段 | 完成什么 | 进入下一阶段的条件 |
|---|---|---|
| P0：运行规格与诊断 | 固定教师配置，记录完整任务事件和失败片段 | 确认瓶颈，观察器不改变行为 |
| P1：上下文恢复 | 保存状态并做配对续跑 | 动态机会没有被 reset 人为改变 |
| P2：生成与探测 | 两层前向分支、自然策略对照和窗口复验 | 得到可重复的时序差异 |
| P3：冻结 bundle | 筛选、同容量组织和物理审计 | 产物完整、可追溯、通过恢复检查 |
| P4：训练接入 | 接入原 SGS／PPO，验证旧路径与异步 reset | 回合和成功统计正确 |
| P5：方法实验 | 主比较、同池消融、完整成本和任务评价 | 收益超过简单方法 |

**第一项工作是收集当前教师首次接触前后的片段，确认它主要败在追赶、闭爪时机还是抓后滑落。** 随后检查同一起点改变一拍闭爪时序是否改变结果，以及这种差异能否在恢复后保留。

离线结果稳定后，再考虑在线库、未见物体与运动条件、其他接触任务和真机实验。多个速度档位属于同一任务的泛化，不等于多个独立任务族。

## 8. 适用边界与真机要求

| 观察结果 | 应采取的判断 |
|---|---|
| 主要失败在远距离接近或感知 | 先处理真正瓶颈 |
| 现有观测无法区分所需动作 | 检查历史或状态估计，课程不能补足缺失信息 |
| 有效窗口短于现有控制分辨率 | 检查控制频率与动作表达能力 |
| 恢复过程显著改变窗口 | 暂停算法比较，先修复恢复 |
| 普通回收获得同等收益 | 保留简单方法，重新界定贡献 |
| 仅局部成功提高，完整任务无改善 | 不扩大在线课程系统 |
| 增益只来自更多计算 | 可以报告性能收益，不能据此声称样本效率提高 |

本方案的接触标签和窗口探测在仿真中使用，部署观测保持既有接口，因此**课程方法本身不要求新增指尖触觉传感器**。真机仍需既定的物体感知和机器人状态输入；若将接触／滑移检测直接用于在线动作切换，则需另行验证传感与估计方案。

真机从完整起点比较现有教师、最强简单基线和新方法。若部署视觉学生，各方法统一感知、学生结构与蒸馏预算；看不清的接触事件标为未知，不把仿真标签当作真机测量。

论文主张应围绕“时序机会的生成是否带来完整任务训练收益”建立。方法效果与新颖性都需要上述证据，不能由模块组合或命名直接推出。
