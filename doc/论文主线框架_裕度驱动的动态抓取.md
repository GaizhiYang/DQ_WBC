## 0. 一句话主张

> **预测物体会去哪（EKF），预测自己多快能到（τ），二者合成拦截裕度；再由裕度同时决定 RL 的三个环节：策略看到什么、奖励什么、在哪里练。**

SGS、EKF 和拦截裕度因此不是三个并列的技巧，而是同一套机制里互相依赖的部件。

**标题候选：**
- *Can I Catch It? Intercept Margins Unify Forecasting, Shaping, and Curricula for Dynamic Mobile Manipulation*
- *From Chasing to Intercepting: Self–Target Factorized Reinforcement Learning for Dynamic Grasping*

## 1. 问题定位

**通用问题**：目标在动、而且目标的运动不受智能体影响时的目标条件 RL。智能体必须同时推断“目标将在哪里”和“自己什么时候能到”。

**主要测试平台**：DQ-Bench 上的腿式机械臂（B1 + Z1）动态抓取。教师从 2 m 外起步，台面横向速度 0.15–0.3 m/s，可选恒定转速。

**这类任务常用的三件套**：物体预测、按距离塑形、按成功率排课程。它们分别在三个地方缺乏前瞻性（第 2 节），本文用一个量统一修正。

## 2. 现有组件的缺口（来自代码）

| 组件 | 回答的问题 | 缺口 | 代码依据 |
|---|---|---|---|
| EKF | 物体会去哪 | 不知道自己来不来得及；在臂基坐标系 A 里拟合相对运动，把机器人自身的运动也当成匀速外推 | [`b1z1_pickmulti.py:780`](../DQ_high-level/envs/b1z1_pickmulti.py#L780) |
| 接近奖励 | 怎么给密集奖励 | `approaching` 和 `base_approaching` 都对准物体**当前**位置，相当于制导里的“纯追踪” | [`reward_vec_task.py:11`](../DQ_high-level/envs/reward_vec_task.py#L11)、[`#L127`](../DQ_high-level/envs/reward_vec_task.py#L127)、[`b1z1_pickmulti.py:761`](../DQ_high-level/envs/b1z1_pickmulti.py#L761) |
| SGS | 在哪里练 | 只看成功率，分不清“还没学会”和“根本来不及”；新配置要冷启动 | [`sgs.py:208`](../DQ_high-level/utils/sgs.py#L208)、[`DQ_teacher.yaml:34`](../DQ_high-level/data/cfg/DQ_teacher.yaml#L34) |

**SGS 的细节。** 权重为 `p^0.5 (1−p)^0.5`，加 ε = 1e-4 的下限，温度 2；没有历史的配置取 `p_init = 0`。所以一个从未成功过的配置，不论“可行但还没学会”还是“物理上来不及”，拿到的都是同一个下限权重。方向 3 生成的新配置一开始也是 p = 0。

**三个缺口有同一个根源：都缺一个“自身能力相对于运动目标”的模型。**

## 3. 方法

### 3.1 总览：一个闭环

```text
   物体预测 g(t+h)  [EKF]          自身最短到达时间 τ(s, g)  [事后标注学习]
            \                               /
             →   拦截裕度  M(s) = max_{i,h} [ h − τ(s, g_i(t+h)) ]   ←
            /                  |                         \
  表征：GFM 时空 token     奖励：拦截势函数          数据：裕度先验的 SGS
   （策略看到什么）         （奖励什么）              （在哪里练）
            \                  |                         /
          rollout 数据  →  更新 τ、SGS 成功率统计、EKF 误差统计
```

### 3.2 物体预测：EKF 的角色和升级

- **角色**：从“GFM Query 的附加观测”变成“裕度中物体那一半”。
- **升级 1：扣掉自身运动。** 用本体里程计（或自身前向模型）把 EKF 窗口里的历史相对位姿变换到同一个坐标系，再做匀速 twist 外推（借鉴文档的建议 B）。
- **升级 2（可选）：不确定性。** 用“实际发生的预测误差”（方向 8）把裕度变成概率 `P(M ≥ 0)`，用于 Level03 / Level04 这类变速运动。
- **训练时的特权版本**：奖励、课程和失败归因只在训练时使用，可以用解析的物体未来。Level02 中物体随台面做恒定 body twist（[`b1z1_base.py:1811`](../DQ_high-level/envs/b1z1_base.py#L1811)），[`utils/sgs_motion.py`](../DQ_high-level/utils/sgs_motion.py) 已有瞬时速度的计算。进入策略观测的 token 仍用 EKF。

### 3.3 自身最短到达时间 τ

- **定义**：`τ(s, g)` 是从状态 `s` 把末端送到位姿 `g` 的最短时间（`g` 表达在 t 时刻冻结的臂基坐标系中），描述底座 + 手臂 + 冻结的底层控制器这个整体。
- **事后标注**：轨迹中“t 时刻状态 → t+k 时刻末端实际到达的位置”构成样本，标签 `k·Δt` 是最短时间的上界。用偏下的 expectile 回归（q ≈ 0.1）逼近下包络；第二版可以换成 QRL。
- **兜底与简化**：用底座最大速度和手臂工作空间给出物理下界；姿态部分先用解析下界（末端姿态每轴每步最多 0.06 rad）。
- **关键性质**：τ 只描述机器人自己、与物体无关，所以所有回合、所有时刻对都能用来训练。
- 细节见 [`机器人自身动力学预测方向构思.md`](机器人自身动力学预测方向构思.md) 第 2 节。

### 3.4 拦截裕度

```text
m(i, h) = h − τ( s_t , g_i(t+h) ),    h ∈ [0, T_max − t]
M(s)    = max_{i, h} m(i, h)
```

- `h` 的上界是剩余时间（`maxEpisodeLength = 100` 步，[`DQ_teacher.yaml:8`](../DQ_high-level/data/cfg/DQ_teacher.yaml#L8)）。随着时间流逝，可行集会自然缩小，裕度本身就带上了时限信息，和方向 0（critic 时间特征）一致。
- 计算量：第一版只对物体中心算位置部分的 τ，抓取之间的差别用解析的姿态项区分。

### 3.5 三个环节

| 环节 | 做法 | 对应的已有方向 |
|---|---|---|
| **表征**（策略看到什么） | 每个时空 token `(i, h)` 带上 `m(i, h)`、`τ`、“是否来得及” | 方向 1（GFM 时空 token） |
| **奖励**（奖励什么） | 拦截势函数 `Φ = κ·clip(M, −c, c)/c`，`F = γΦ(s') − Φ(s)`，替换追踪式的 `approaching` 和 `base_approaching`；物体抬起后关闭 | 取代方向 1(d) 的距离势函数 |
| **数据**（在哪里练） | **贝叶斯 SGS**：先验 `p₀(c) = σ((M₀(c) − b)/T)`，用观测到的成功、失败更新；`M₀` 明显小于 0 的配置标记为不可行；方向 3 生成新配置时先用 `M₀ ∈ [0, δ]` 筛选 | 方向 3（配置库在线演化） |

**贝叶斯 SGS 的具体形式：**

```text
先验     Beta( n₀·p₀(c),  n₀·(1 − p₀(c)) )
后验均值 p̂(c) = ( 成功次数 + n₀·p₀(c) ) / ( 总次数 + n₀ )
权重     沿用现有核 p̂^0.5 (1 − p̂)^0.5、ε 下限和温度
标定     b、T 用最近回合的 (M₀, 成败) 做逻辑回归拟合
```

它替换的只是 `p_init = 0` 这个约定（[`DQ_teacher.yaml:35`](../DQ_high-level/data/cfg/DQ_teacher.yaml#L35)）和 `success_rates()` 的计算，采样核不变，改动集中在 [`utils/sgs.py`](../DQ_high-level/utils/sgs.py)。

## 4. 理论命题

命题都不复杂，作用是给论文一个清楚的“AI 骨架”。

**P1（分解）。** 假设：(a) 抓取前目标运动不受智能体影响；(b) 智能体可以提前到达某个位姿并原地保持（底座能站住、手臂能保持末端）。那么最早拦截时间为

```text
T*(s) = min { h ∈ [0, T_max − t] : τ*(s, g(t+h)) ≤ h }
```

*证明思路*：若 `τ* ≤ h`，智能体可以在 `t + τ*` 到达 `g(t+h)` 并保持到 `t + h`；反之，若能在 `t + h` 拦截，则到达 `g(t+h)` 的时间不超过 `h`。由 (a)，`g(t+h)` 与智能体的动作无关。

*推论*：τ 只描述机器人自己，学一次就能用于任意目标运动。这给出一个可检验的泛化主张：在 Level02 上学到的 τ，直接用于 Level01–05（运动模式见 [`b1z1_base.py:1904`](../DQ_high-level/envs/b1z1_base.py#L1904)）。

*限定*：抓取还需要接触时速度匹配，所以 `M ≥ 0` 是成功的必要条件，不是充分条件。这正好对应失败类型 F3。“原地等待”也忽略了等待期间与台面的接触。

**P2（可行集）。** `{s : M(s) ≥ 0}` 恰好是“剩余时间内来得及拦截”的状态集合，相当于 Hamilton-Jacobi 可达性中的后向可达集；M 可以看成一个基于时间的可达性值函数。

**P3（塑形不变性）。** 用特权的解析未来计算时，Φ 是（含时间的）真实状态的函数，按 Ng 等（1999）的结论不改变最优策略。τ 随训练慢慢更新时，严格保证不再成立，属于实践上的近似（参见 Devlin & Kudenko 2012 的动态势函数）。

**P4（课程）。** 若执行噪声下成功率近似为 `p(s) ≈ σ((M(s) − b)/T)`，则 SGS 的学习性权重 `p(1−p)` 在 `M = b` 处最大。因此：
- `M₀` 是能推广到没试过的配置的成功率先验；
- `M₀ > 0` 而 `p ≈ 0` 表示“可行但还没学会”，应该得到更多练习，而不是停在下限权重；
- `M₀ ≪ 0` 表示不可行，不应当作“难题”反复练习。

这条近似关系本身可以用诊断 D3 检验。

## 5. 为什么不是孤立的：四种耦合

1. **结构耦合**：裕度需要 EKF 提供物体那一半、τ 提供自身那一半，缺一个就算不出来。
2. **奖励帮课程**：拦截塑形让 full_task 配置更早出现成功，SGS 的统计更早有用，冷启动缩短。
3. **课程帮模型**：SGS 把练习集中在 `M ≈ 0` 附近，τ 正好在最需要准的地方拿到数据，类似主动学习。风险是自我强化的偏差，由 SGS 的实际成功率统计纠正。
4. **统一的评估**：失败归因同时检验三处。F1（一直来不及）减少，说明课程起效；F2（裕度在途中丢失）减少，说明塑形和选择起效。

**用析因消融展示耦合**：表征、奖励、课程三项各开 / 关，共 2³ = 8 组。除了主效应，还报告交互效应，例如“奖励 × 课程”。这比三个独立的消融更能说明它们是一个整体。

## 6. 实验计划

### 6.1 先过三道关（决定故事能不能成立）

| 诊断 | 做法 | 支撑的论点 | 不通过时 |
|---|---|---|---|
| **D1 追尾** | 用现有教师 checkpoint，统计接近阶段的视线角速率、朝向与视线的夹角、路径长度与直线拦截路径之比 | 奖励环节：追踪式塑形有害 | 奖励环节变弱，故事重心移到课程和表征 |
| **D3 裕度的预测力** | 离线训练 τ，计算每个配置的 `M₀`，看它对配置成功率的 AUC，并检验 P4 的 sigmoid 近似 | 课程环节，以及 τ 本身是否可用 | 先改进 τ；仍不行就放弃课程环节 |
| **D5 SGS 冷启动** | 从训练日志统计 full_task 配置停在下限权重的比例和持续时长 | “成功率课程分不清没学会和不可能”这个前提 | 课程环节的动机变弱 |

另外两项辅助诊断：**D2**（τ 的误差和校准曲线，与物理下界、指令积分两个基线比较）和 **D4**（当前教师失败中 F1 / F2 / F3 的比例）。

### 6.2 主实验

| 组 | 内容 |
|---|---|
| B0 | PPO + 原塑形（无 SGS、无 EKF） |
| B1 | DQ-Net（前作，AAAI 2026） |
| B2 | 当前 SGS + EKF 教师（含方向 0） |

### 6.3 对照方法

- **塑形**：按“到预测点的距离”塑形（方向 1(d)）；DDL 式的静态到达时间塑形。
- **课程**：均匀采样、原 SGS、PLR / SFL、BaRC 式的起点扩展。
- **模型类**：Dyna 式 PPO 或 RWM 式的世界模型，用来说明“为样本效率学模型”和“为可行性学模型”的区别。

### 6.4 泛化

- **跨运动模式**：在 Level02 上训练，在 Level01 / 03 / 04 / 05 上测试，τ 不重新训练（P1 的推论）。Level03 / 04 需要结合方向 8 的不确定性。
- **跨动力学**：附加质量、摩擦取极端值；台面速度超出训练范围。
- **跨物体**：仓库支持多物体配置。
- **跨领域**（投 NeurIPS / ICML / ICLR 时建议加）：再做一个更简单的拦截任务，例如固定臂拦截运动物体、点质量或四足追逐移动目标，证明方法不依赖 B1Z1。

### 6.5 指标与分析图

- **指标**：full_task 成功率、成功用时、视线角速率、路径长度、F1 / F2 / F3 比例、`ik_fail` 终止率。至少 3 个随机种子。
- **分析图**：
  1. 典型回合的裕度曲线 `M(t)` 和失败构成；
  2. 追踪式与拦截式塑形下视线角速率的分布；
  3. `M₀` 与配置成功率的校准曲线；
  4. 训练过程中 SGS 权重的分布（冷启动是否缓解）；
  5. GFM 注意力与 token 裕度的关系。

## 7. 相关工作定位（审稿人一定会问）

| 工作 | 本文的区别 |
|---|---|
| HJ 可达性 / reach-avoid RL（Fisac 2019；Hsu 2021） | 它们用 Bellman 方程学习针对静态目标集合的可达值，目标要放进状态里。本文把只描述自身的到达时间和外生的目标预测组合起来，模块化，τ 可以复用 |
| **BaRC**（Ivanovic et al.） | **课程环节最接近的前作**：用近似解析动力学的后向可达集，从目标向外扩展起点。本文的 τ 是学出来的，目标在动，和 SGS 的成功率统计结合，而且裕度同时用于奖励和表征 |
| PAIRED、SFL、ACCEL | 用 regret 或学习性避开不可解的关卡，依赖第二个智能体或成功率统计。本文在跑 rollout 之前就有基于模型的可行性估计 |
| DDL、QRL | 学习到达时间，但目标静止，没有和目标预测组合 |
| 分解式拦截（AAAI 2023：预测 + 路径规划 + 控制） | 那是模块化流水线。本文保留端到端的 RL 策略，分解只用于特征、奖励和课程 |
| 世界模型（RWM、Dyna-PPO） | 目的是样本效率，不是可行性 |
| 动态抓取 RL（DQ-Net、GAP-RL、DynaMOMA） | 只预测物体，自身能力交给策略隐式学习 |
| 可达性先验（Jauhri 2022；Akinola 2021） | 静态可达性，没有时间维度 |

## 9. 投稿层面的判断与风险

**会议选择。** AAAI、IJCAI 对应用型工作接受度更高，DQ-Bench 加上第 4 节的命题和析因消融就比较完整。NeurIPS、ICML、ICLR 更看重通用性，建议加上 6.4 的跨领域实验。截稿日期以官网为准。

**风险：**
- **“提前量”这个前提可能不成立**：如果 D1 显示当前策略不怎么追尾，奖励环节会变弱。
- **理论偏轻**：P1–P4 都是简单命题，需要靠通用性实验和干净的析因消融支撑“这是方法，不是工程”。
- **特权信息**：奖励和课程使用训练时的特权预测，这是非对称训练的常见做法；策略输入只用 EKF。
- **必要不充分**：`M ≥ 0` 不保证抓取成功，F3 类失败不在本文的改进范围内，需要在论文里说清楚。
- **计算量**：裕度计算的开销要单独报告。

## 10. 推进顺序

1. **D1、D5**：不需要新模型，直接用现有 checkpoint 和训练日志。
2. 离线训练 τ，做 **D2、D3、D4**。
3. **奖励环节**（Ours-R）：只改奖励，是最干净的单变量实验。
4. **课程环节**（Ours-RC）：贝叶斯 SGS，改动集中在 `utils/sgs.py`。
5. **表征环节**（Ours）：依赖方向 1 对 GFM 的改造，改动最大。
6. 析因消融、泛化实验，以及（如果投 ML 会议）跨领域实验。
