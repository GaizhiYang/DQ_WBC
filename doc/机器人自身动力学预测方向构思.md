# 拦截裕度：用学到的机器人自身动力学，把“追逐”变成“拦截”

> 对象：[`train_teacher_sgs_ekf.sh`](../DQ_high-level/train_teacher_sgs_ekf.sh) 启动的 sugar_box 教师（skrl PPO + SGS + EKF，Level02 运动台面）。
> 本文只做构思，**没有改代码，也没有跑实验**；收益都是待验证的假设。代码位置已逐一核对；新颖性判断只基于有限的检索。
> 修订记录：2026-11-14 初版以“自我前向模型”（M1–M3）为主线。2026-11-15 讨论后认为，学习机器人动力学本身不新，新颖性取决于用它做什么，于是改为以**拦截裕度**为主线，自我前向模型降为支撑组件（第 7 节）。
> 相关文档：[`dynamic_papers_借鉴分析.md`](dynamic_papers_借鉴分析.md)（建议 A / B / G）、[`教师训练创新方向分析.md`](教师训练创新方向分析.md)（方向 0–11）。
> 论文层面的主线（拦截裕度如何与 SGS、EKF 组成一个整体）见 [`论文主线框架_裕度驱动的动态抓取.md`](论文主线框架_裕度驱动的动态抓取.md)。

## 0. 一句话

世界模型和机器人动力学学习都不是新东西。本文的主张是：

> 学一个“**这台机器人最快多久能把手送到某个位置**”的模型，再和物体预测组合成**拦截裕度**——“我还来不来得及在某个时刻到达某个抓取点”。然后把这一个量接进训练的四个地方：**塑形、选择、课程、失败归因**。

动机来自代码：现在的两个接近奖励看的都是物体**当前**位置，相当于制导里的“纯追踪”。机器人被鼓励去追物体现在的位置，而不是去物体将要到的地方。

---

## 1. 代码现象：塑形奖励在教“追”，而不是“拦”

### 1.1 两个接近奖励都对准物体当前位置

- `approaching`：末端到物体**当前**位置的距离每创一次新低就给奖励（[`reward_vec_task.py:11`](../DQ_high-level/envs/reward_vec_task.py#L11)；距离在 [`b1z1_pickmulti.py:761`](../DQ_high-level/envs/b1z1_pickmulti.py#L761) 计算），权重 0.5。
- `base_approaching`：臂基到物体**当前**位置的水平距离越接近 `baseObjectDisThreshold = 0.2 m`，奖励越大（[`reward_vec_task.py:127`](../DQ_high-level/envs/reward_vec_task.py#L127)），权重 0.01。

### 1.2 这在本任务里影响有多大

- 评估从 2 m 外起步（[`DQ_teacher.yaml:15`](../DQ_high-level/data/cfg/DQ_teacher.yaml#L15)），底座最快约 0.45 m/s。臂基在底座前方 0.3 m，要走到 `base_approaching` 的目标距离 0.2 m，按最大速度也要约 3.3 s。
- 这段时间里台面横向移动约 0.5–1.0 m（0.15–0.3 m/s），和起步距离是同一个量级。
- 对准当前位置就是制导里的**纯追踪**（pure pursuit）：目标横向运动时，追的一方会绕到目标后方“追尾”，路径更长、到得更晚。人和狗拦截运动目标时用的是**恒定方位角**策略（Fajen & Warren 2007；Shaffer et al. 2004），也就是提前去目标将要到的地方。
- 成功奖励最终仍可能把策略拉向“提前拦截”，但早期的密集塑形一直在把它往“追”的方向推。实际影响有多大，要先用诊断 D1 量出来（第 5 节）。

### 1.3 为什么不能直接套用经典拦截

恒定方位角、比例导引都假设追的一方能自由选择速度。本任务里，“多快能到”取决于机器人自己：

| 因素 | 代码位置 | 影响 |
|---|---|---|
| 底座指令上限 ±0.45 m/s，yaw ±0.6 rad/s | [`clip_commands`](../DQ_high-level/envs/b1z1_base.py#L2173)、[`b1z1_base.py:2139`](../DQ_high-level/envs/b1z1_base.py#L2139) | 速度有上限 |
| 小指令整体置零（\|vx\| ≤ 0.15 且 \|yaw\| ≤ 0.35） | [`b1z1_base.py:2141`](../DQ_high-level/envs/b1z1_base.py#L2141) | 低速段强烈非线性 |
| 冻结的底层策略控制腿，走 / 停之间有过渡 | [`b1z1_base.py:1724`](../DQ_high-level/envs/b1z1_base.py#L1724) | 起步、刹车有滞后 |
| 末端目标每轴每步最多 0.02 m，姿态每轴 0.06 rad | [`b1z1_base.py:2098`](../DQ_high-level/envs/b1z1_base.py#L2098) | 手臂“慢”：0.9 s 内每轴最多 0.12 m |
| 躯干附加质量 0–15 kg、摩擦 0.5–3.0，不进观测 | [`b1z1_base.py:244`](../DQ_high-level/envs/b1z1_base.py#L244)、[`#L876`](../DQ_high-level/envs/b1z1_base.py#L876) | 同样的命令，不同环境响应不同 |
| 教师观测是单帧，底座速度被 `--no_velocity_obs` 删掉 | [`b1z1_pickmulti.py:897`](../DQ_high-level/envs/b1z1_pickmulti.py#L897) | 策略看不到自己正在怎么动 |

所以“该提前多少”没有解析答案，必须学习机器人自身的动力学。**在这里，学习自身动力学是必需的，而不是可有可无的附加项。**

## 2. 核心概念：拦截裕度

### 2.1 定义

```text
m(i, h) = h − τ( s_t , g_i(t+h) )          拦截裕度
M(t)    = max_{i, h} m(i, h)                当前最好的裕度
h*(t)   = min { h : max_i m(i, h) ≥ 0 }     最早来得及的拦截时刻
```

- `g_i(t+h)`：第 `i` 个候选抓取在 `t+h` 时刻的位姿，表达在 **t 时刻冻结的臂基坐标系 Ā_t** 中（这个坐标系在世界中固定，不随机器人之后的运动变化）。
- `τ(s, g)`：从当前状态 `s` 把末端送到 Ā_t 中位姿 `g` 的**最短时间**，描述的是这台机器人（底座 + 手臂 + 冻结的底层控制器）。
- `m ≥ 0` 表示来得及；`m` 越大，余量越多。`M(t)` 随时间的变化记录了“拦截机会”是在变多还是在流失。

### 2.2 物体的未来位姿从哪来

| 用途 | 来源 | 理由 |
|---|---|---|
| 塑形、课程、失败归因 | **特权真值**：Level02 中物体随台面做恒定 body twist，抓取前的未来位姿可以解析算出（[`utils/sgs_motion.py`](../DQ_high-level/utils/sgs_motion.py) 已经实现了瞬时速度，把它积分到 `t+h` 即可） | 只在训练时使用，部署时不需要 |
| 进入策略观测（token 特征） | EKF 预测（可用第 7.3 节的分解预测改进） | 学生能复现 |

四个用法里有三个**不改变策略的观测**，也就不影响学生端。

### 2.3 τ：学习自身的最短到达时间

**输入**：本体状态（可直接用环境已有的 `low_obs_history_buf`，见 [`b1z1_base.py:387`](../DQ_high-level/envs/b1z1_base.py#L387)，含底座角速度、关节、指令、末端目标和步态时钟）、当前末端目标，以及目标位置 `g`（Ā_t 中）。

**事后标注**：每条轨迹里，“t 时刻的状态 → t+k 时刻末端实际到达的位置（表达在 Ā_t 中）”就是一个样本，标签是 `k·Δt`。

- 实际耗时只是最短时间的**上界**：策略当时并没有在“尽快到达那个点”。所以用偏下的 expectile 回归（IQL 的做法）逼近观测到的耗时的下包络：

  ```text
  L(τ) = | q − 1(k·Δt − τ < 0) | · (k·Δt − τ)²,     q ≈ 0.1
  ```

- 更有理论保证的做法是 QRL：用拟度量（quasimetric）结构直接学最优到达时间。可以作为第二版。
- **物理下界兜底**：用底座最大速度和手臂工作空间给出 `τ_floor`，取 `τ = max(τ_learned, τ_floor)`，防止网络在没见过的区域过于乐观。
- **姿态先解析处理**：`τ_orn = max_axis |Δrpy| / 0.06 rad` 步，第一版取 `τ = max(τ_pos, τ_orn)`，网络只学位置部分。

**数据量**：τ 只描述机器人自己、与物体无关，所以所有回合、所有时刻对都能用。但 PPO 的 rollout 只有 24 步，而 τ 需要几秒的跨度，所以要按回合维护轨迹缓冲（每个环境 100 步 × 约 40 维，8192 个环境约 130 MB）。

**和策略的关系**：下包络随策略变强而变小。τ 用独立的优化器训练，奖励和课程使用它的 EMA 目标网络，让它慢慢变化。

### 2.4 计算量

30 个抓取 × 16 个时刻（0.3 s 间隔到 4.8 s）= 每个环境每步 480 次 τ 前向，8192 个环境约 400 万次小 MLP 前向，可以接受但不便宜。

sugar_box 很小，第一版只对**物体中心**算位置部分 `τ_pos`（每个环境 16 次），各个抓取之间的差别只通过解析的 `τ_orn` 区分。

## 3. 一个量，接进四个地方

### 3.1 塑形：用拦截势函数替代追踪式塑形

```text
Φ(s) = κ · clip( M(t), −c, c ) / c
F    = γ · Φ(s') − Φ(s)                 物体被抬起后关闭（与 approaching 相同）
```

- **两种接法**：替换 `approaching` + `base_approaching`；或者保留它们、额外加上 `F`。前者是更干净的对照。
- **理论**：Φ 只依赖状态，按 Ng 等（1999）的势函数塑形，不改变最优策略。由于 τ 会慢慢更新，严格来说 Φ 是随时间变化的势函数（Devlin & Kudenko 2012 讨论了这种情形），这里属于实践上的近似。
- **和方向 1(d) 的关系**：方向 1(d) 的 `Φ = −min 距离` 是它的粗糙版，用的是距离而不是时间，只看到 0.9 s，而且不管机器人能不能到。这里换成了时间，并且考虑了机器人自身的能力。
- **预期效果**：减少追尾，缩短成功用时，加快早期学习。

### 3.2 选择：token 带上裕度

- 每个时空 token `(i, h)` 增加 `m(i, h)`、`τ` 和“是否来得及”（共 3 维），其中 `g` 用 EKF 预测。
- GFM 的注意力就在“来得及的拦截”里做选择。是挑最早来得及的，还是余量最大的，交给 RL 去学。
- 这一条依赖方向 1 对 GFM 的改造（G2 组），可以合并成一组实验。抓住物体后，屏蔽 `h > 0` 的 token。

### 3.3 课程：不跑 rollout 就能算出初态可行性

对配置库里的每个配置 `c`，用重置时的状态算 `m₀(c) = M(0)`（物体未来用解析真值）。1536 个配置全部重算一次很便宜，可以每隔若干次迭代刷新。

| 用法 | 做法 |
|---|---|
| 检验 τ 是否可靠 | `m₀` 对配置近期成功率的 AUC（诊断 D3） |
| 识别不可能的初态 | `m₀ < 0` 的配置在物理上来不及，不应该当作“难题”反复练习，可以降权或单独统计 |
| 指导方向 3 的变异 | 变异出的候选配置先用 `m₀ ∈ [0, δ]` 筛选，再交给 `sgs_bank_builder` 做物理验证 |
| 课程进度 | 让余量 `δ` 随训练逐渐变小，从“宽裕”练到“刚好来得及” |

SGS 现在用成功率衡量难度。`m₀` 补上了两样东西：对**没试过的配置**（例如变异出来的配置）的先验，以及“为什么难”的解释。

### 3.4 失败归因：论文里的分析图

对每个回合记录裕度曲线 `M(t)`：

| 类型 | 判据 | 含义 | 对应改进 |
|---|---|---|---|
| F1 一直来不及 | `max_t M(t) < 0` | 初态不可行，或策略从一开始就走错 | 课程（3.3） |
| F2 裕度丢失 | `M` 曾经 ≥ 0，但在接触前降到 < 0 | 决策错误；最后一次由正转负的时刻 `t_loss` 是“不可挽回点” | 塑形（3.1）、选择（3.2） |
| F3 到了没抓住 | 末端进入抓取距离时 `M ≥ 0`，但抓取、抬升或保持失败 | 执行问题 | 与本方向无关（接触、夹爪时机） |

- 比较各方法的 F1 / F2 / F3 比例，以及典型回合的 `M(t)` 曲线，就能说明“改进到底改善了哪一类失败”。
- `t_loss` 还可以作为方向 9 的回标时刻，`M(t)` 也可以作为方向 10 的阶段变量。

## 5. 实验设计

### 5.1 离线诊断（用现有教师 checkpoint，不改训练）

| 诊断 | 做法 | 决定什么 |
|---|---|---|
| **D1 有没有追尾** | 接近阶段统计视线角速率 `dλ/dt`、底座朝向与视线的夹角、路径长度与直线拦截路径之比。纯追踪的特征是“朝向对准视线、视线在转”；恒定方位角拦截的特征是“视线角速率接近 0” | 追尾不明显，3.1 的收益就小 |
| D2 τ 的质量 | 留出数据上的误差；与只用物理下界、与“按指令积分”两个基线比较；画校准曲线 | τ 能否用 |
| **D3 m₀ 的预测力** | `m₀` 对各配置成功率的 AUC | AUC 高，说明 τ 有效，3.3 站得住 |
| D4 当前教师的失败构成 | F1 / F2 / F3 的比例 | F1 多就先做 3.3；F2 多就先做 3.1、3.2；F3 多说明瓶颈不在这里 |

D1 不需要 τ，可以最先做。

### 5.2 训练对照

| 组 | 内容 | 要回答的问题 |
|---|---|---|
| T0 | 当前基线（含方向 0） | — |
| **T1** | 用拦截势函数替换 `approaching` + `base_approaching` | **主假设**：拦截式塑形是否优于追踪式塑形 |
| T1′ | 保留原有塑形，额外加拦截势函数 | 替换还是叠加 |
| T2 | T1 + token 带上裕度（与方向 1 的 G2 合并） | 显式可行性信息是否改善选择 |
| T3 | T2 + `m₀` 指导的 SGS 与变异（与方向 3 合并） | 裕度课程是否有效 |

**指标**：full_task 成功率、成功用时、视线角速率、路径长度、F1 / F2 / F3 比例、`ik_fail` 终止率。

**泛化**：附加质量和摩擦取极端值；台面速度超出训练范围；Level03 / Level04（需要结合方向 8 的不确定性）。

## 6. 实现要点（贴合代码）

- **环境导出**：每步在 `extras` 中放入机器人根状态、臂基位姿、末端位姿、末端目标和分开的终止原因。这些量环境里都已经算出来了。
- **轨迹缓冲**：按环境维护整回合（最多 100 步）的本体量和末端位置，回合结束后生成 τ 的事后标注样本。
- **τ 网络**：独立模块、独立优化器，单独注册 checkpoint；奖励和课程使用 EMA 目标网络。
- **奖励接入**：在奖励表里新增一项（例如 `intercept_potential`），在环境里实现 `_reward_intercept_potential`。环境需要持有 τ 网络的引用，可以在环境创建后注入。
- **解析的物体未来**：把 `sgs_motion.py` 里的瞬时速度扩展成“`t+h` 时刻的位姿”（对台面的恒定 body twist 积分，物体随台面运动），只在接触前有效，接触或抬起后用掩码关闭。
- **token 特征**：依赖方向 1 对 GFM 的改造。
- **课程**：每隔若干次迭代对全部配置重算 `m₀`，作为 SGS 采样的先验或过滤条件。

## 7. 支撑组件：自我前向模型（初版的 M1–M3）

τ 可以直接学，不必经过逐步的前向模型。前向模型仍然有用，但定位改为支撑组件和低成本增益项。

### 7.1 自我前向模型的定义

```text
f_θ( 本体历史 o_{t−K+1 : t},  未来动作 a_{t : t+k−1} )  →  ŷ(t+k),    k ∈ {1, 2, 4, 6}
```

| 目标 | 定义 | 损失 |
|---|---|---|
| Y1 臂基位移 | `T(A_t → A_{t+k})`：Δx、Δy、Δyaw，加高度和 roll / pitch 小量 | Smooth L1 |
| Y2 末端位姿 | 末端在 A_t 中的位姿 | Smooth L1 |
| Y3 末端跟踪误差 | 末端目标 − 实际末端 | Smooth L1 |
| Y4 失败事件 | k 步内是否 `ik_fail`（[`b1z1_base.py:1628`](../DQ_high-level/envs/b1z1_base.py#L1628)）/ 姿态终止 / yaw 超限 | BCE |
| Y5 当前速度（k = 0） | 底座线速度、角速度，补上被删掉的速度观测 | Smooth L1 |

- **关键性质**：给定动作序列后，这个映射描述的是“冻结的底层控制器 + 机器人本体”，与高层策略无关。策略在变，要学的映射不变，变的只是数据分布。
- **动作假设**：训练时用实际执行的动作；使用时用“保持上一动作”（H0）或“停 / 保持 / 加速”三个底座原语（H1）。
- **结构**：多步直接输出（k ≤ 6，不做自回归），5 个小模型组成集成，用方差表示不确定性（同 RWM-U）。

### 7.2 用法：自我状态嵌入进入策略

参考 HIM 和 RMA：从本体历史估计“显式底座速度 + 隐式嵌入”，作为策略的额外输入；隐式部分用 Y1–Y4 的预测损失训练。它补全了单帧观测缺失的自身运动状态，以及隐藏的附加质量和摩擦。方法本身是通用的，适合作为消融里的 “+trick”，不作为创新点。

### 7.3 用法：自我–物体分解，改进进入策略的物体预测

现在 EKF 在 A 系里外推相对运动（[`b1z1_pickmulti.py:780`](../DQ_high-level/envs/b1z1_pickmulti.py#L780)），隐含了“机器人保持最近的匀速运动”。可以改为：

```text
① 用 Y1（或本体里程计）把 EKF 窗口里的历史相对位姿变换到当前坐标系，扣掉过去的自身运动
② 在这个坐标系里对物体做匀速 twist 外推
③ 自我模型在动作假设下预测自身将来的位移
④ 组合得到将来的相对位姿
```

第 ① 步就是建议 B2，只是用学到的里程计代替“指令积分”。这一条改进的是第 3.2 节 token 里用到的 `g_i(t+h)`。

### 7.4 初版的“可达拦截 token”

初版用“距离差 + 每轴步数上限”判断能否够到，现在被第 3.2 节的时间裕度取代：后者把底座和手臂统一成同一个“到达时间”，也考虑了底层控制器的滞后。

### 7.5 次要用法

- **区分“谁让物体动了”**（efference copy）：观测到的相对运动，减去自我模型预测的部分，再减去台面运动预测，剩下的就是推挤或物体被夹着走造成的。触须机器人用同样的原理检测接触（Anderson et al. 2010）。教师可以直接拿到特权接触信息，所以这一条主要对学生 / 真机有用。
- **底座 / 手臂的反事实信用分配**：用自我模型加物体预测做一步前瞻，得到“如果底座命令换一个会怎样”的 COMA 式基线（Foerster et al. 2018），可以替代方向 10 中启发式的 β。需要预测完整观测，代价大。
- **不建议**：Dyna 式补充数据（本任务仿真不贵，而且奖励依赖物体和接触）、MPC 细化（与 PPO 的 on-policy 假设冲突）、价值扩展（Palenicek 等发现收益递减）。

## 8. 风险

- **τ 的质量**：下包络只覆盖策略见过的区域，没见过的地方靠物理下界兜底；先学位置，姿态用解析下界。
- **势函数非平稳**：τ 用 EMA 目标网络慢更新；如果仍不稳定，就分阶段冻结 τ。
- **奖励权重需要重新平衡**：替换 `approaching`（0.5）和 `base_approaching`（0.01）后，`κ` 要重新调，并检查 `pick_up` 等其他项的相对尺度。
- **计算量**：见 2.4，先用物体中心近似。
- **长时域物体预测**：Level02 的解析未来是准确的；Level03 / Level04 会切换速度，远期裕度不可靠，需要结合方向 8 的不确定性，或者对远期裕度打折。
- **策略可能本来就学会了提前量**：如果 D1 显示追尾不明显，3.1 的收益会小，主线转向 3.3 和 3.4。

---

## 9. 推进顺序

1. **D1**：不需要 τ，直接用现有 checkpoint 量追尾程度。
2. 离线训练 τ，做 **D2、D3、D4**。
3. **T1**：只改奖励，这是主实验。
4. **T2**：和方向 1 的时空 token 一起做。
5. **T3**：和方向 3 的配置库演化一起做。
6. 视需要加入第 7 节的支撑组件（7.2 自我状态嵌入、7.3 分解预测）。
