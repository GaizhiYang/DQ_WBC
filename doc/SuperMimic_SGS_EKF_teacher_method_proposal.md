# 融合 SuperMimic 的 SGS＋EKF 教师策略改进方案

初稿日期：2026-11-01。2026-11-05 同步已实施的动作路径：真实 PPO 保留随机采样；夹爪改为 `[0,1]` 连续开度；BPTT 使用全部9维 latent 均值，第6维经 sigmoid 后保留梯度，标准差仅由 PPO 更新。本文其余可选研究设计不因此视为已实现或已验证；当前代码范围见[实现说明](SuperMimic_SGS_EKF_implementation.md)。

基线入口：[train_teacher_sgs_ekf.sh](../DQ_high-level/train_teacher_sgs_ekf.sh)。研究对象是当前 Isaac Gym 中的四足移动机械臂动态抓取教师，使用 SGS、EKF 未来位姿观测和 PPO。本文关注方法动机、数据、状态、学习目标及验证逻辑，不规定代码结构、接口、超参数或开发排期。

## 1. 方案要回答的核心问题

**用 SGS 提前获得关键接触经验，学习动作条件化的高层世界模型，再通过短期 BPTT，将预测回报和真实经验训练的长期价值所提供的梯度传回 Actor，共同改进教师策略。**

当前 SGS 主要改善“从哪里开始练习”，EKF 主要改善“如何估计目标未来运动”，PPO 根据实际执行结果改进策略。本方案增加一个能力：预测“如果机器人执行不同动作，机器人和物体接下来会发生什么变化”，并利用这些预测提供额外的动作改进方向。

研究假设是：SGS 的多样初态能够更早提供接触、夹取、失抓和保持数据；共享世界模型能够复用这些经验；短期模型与长期价值的配合，能够把局部动作改进转化为完整任务成功。

这条因果链的每一环都需要验证。模型预测更准，不自动意味着策略更好；想象回报更高，也不自动意味着实际抓取成功率更高。

**推荐的主方案是“真实 PPO 更新＋短期模型 BPTT 更新”。** BPTT（Backpropagation Through Time，通过时间反向传播）用于将多步想象回报沿世界模型传回策略，是所选“模型直接提供动作改进梯度”路线的必要组成。保留 PPO 不代表不使用 BPTT，两条学习路径同时作用于教师。

将 PPO 完全替换为原版 SuperMimic 式训练，属于后续对照方向。历史困难配置复习、特权 Critic、显式成功概率和模型不确定性驱动的真实采样，分别作为增强项研究，避免一开始把所有变化混在一起。

## 2. 当前基线与研究边界

以下事实以指定入口和当前配置为准，而不是此前讨论中的旧版本。

| 组成部分 | 当前含义 | 本方案的处理 |
|---|---|---|
| 物理环境 | Isaac Gym 中的四足、机械臂、夹爪、物体和运动台面 | 保留，作为数据来源和主要评估环境 |
| 任务 | sugar_box、Level02；完整任务起点距目标约 2 m | 主实验固定任务定义 |
| SGS | full_task、pregrasp、near_goal 初态；按近期成功率采样，目标成功率为 0.5 | 保留原始采样作为主基线 |
| EKF | 使用物体历史位姿和时间，给出 0.60／0.90 秒预测 | 保留 Actor 接口，并研究其作为世界模型运动先验的价值 |
| 高层策略 | PPO；动作包含末端位姿增量、夹爪连续开度和底盘运动命令 | 真实 PPO 继续训练，短期模型 BPTT 辅助可信的连续动作改进 |
| 低层控制 | 已有冻结低层控制器，带控制历史 | 世界模型学习执行高层动作后的等效闭环结果 |
| 当前 Critic | 与 Actor 使用同一观测空间，估计累计任务回报 | 先保留真实回报学习，再评估是否需要训练侧状态增强 |
| 成功标准 | 达到抬升、距离和闭爪条件，并连续保持 10 个高层步 | 真实评价与 SGS 成功统计沿用此标准 |

指定入口默认使用普通 PPO；仓库中的 TSIL 是另一个可选分支，不作为本方案的默认组成部分。先固定 SGS＋EKF＋PPO，才能清楚判断模型辅助的贡献。

当前成功条件是任务层面的抓取代理，不是接触力验证。闭爪命令、接近物体和满足高度条件，不能直接作为“稳定物理抓持”的真值标签。

SGS 的 family 是初态类别，不是执行阶段。一次从 full_task 开始的回合也会经历接触和保持；一次 near_goal 重置也可能立即滑落。初态通过已有验证，不等于它必然长期稳定，也不等于完整任务策略一定能到达那里。模型需要同时学习正常完整轨迹中的相应阶段。

## 3. 从 SuperMimic 借鉴什么

SuperMimic 在普通物理仿真器中采集状态转移，学习可微动力学模型，再通过 BPTT 沿短期想象轨迹反向传播回报。物理仿真器负责产生经验，梯度通过神经网络世界模型传播。其方法不要求物理仿真器本身提供梯度，因此继续使用 Isaac Gym 在方法上可行。

| SuperMimic 的思想 | 本方案如何使用 | 证据归属 |
|---|---|---|
| 多个参考动作共享同一动力学模型 | 同一机器人—物体系统的不同 SGS 初态和任务阶段共享模型 | 原文原则的任务迁移 |
| 当前策略采样，模型与策略交替学习 | 从真实 PPO 交互中持续获得数据，随策略变化更新模型 | 原文原则 |
| 多步自回归拟合 | 检验连续预测接近、接触、抬升和保持的能力 | 原文原则 |
| 短期模型回报＋末端 Critic | 用短期模型指导局部动作，用真实经验训练的价值评价后续前景 | 价值来源经过改动，属于混合扩展 |
| BPTT 穿过模型，利用状态和动作的导数更新 Actor | 在可信区域用短期 BPTT 辅助连续动作优化，真实 PPO 保留 | BPTT 来自原文，混合更新属于扩展 |
| 显式条件化随机物理参数，分离观测噪声 | 模型学习尽量确定的物理转移，Actor 保留可用观测 | 原文原则 |
| 当前困难＋历史困难重置采样 | 可给 SGS 增加少量历史复习 | 新采样规则需独立验证 |

原文已经包含足地、身体与地面接触，不能概括为“只学习无接触的机器人自身运动”。但它没有验证物体操作；抓取、滑移和失抓建模，是本方案的重要新增难点。

原文 Critic 使用想象轨迹的 λ-return 训练。本方案主要使用真实仿真经验训练价值，不能将二者写成相同流程。原文也没有验证“SGS＋EKF＋PPO＋接触世界模型”的组合。

原文的世界模型学习窗口为 8 步、想象窗口为 32 步，控制周期为 0.02 秒，分别对应 0.16 秒和 0.64 秒。当前 DQ 高层周期约为 0.14／0.16 秒，窗口应按物理时间和预测可靠性选择，不照搬步数。

## 4. 推荐的整体方法

~~~mermaid
flowchart TD
    A["SGS：选择真实仿真初态"] --> B["Actor 在 Isaac Gym 中执行"]
    B --> C["真实状态转移、奖励和回合结果"]
    C --> D["真实 PPO：更新 Actor 与长期价值"]
    C --> E["共享世界模型：学习高层闭环转移"]
    C --> F["选择可信的真实轨迹起点"]
    E --> G["短期闭环想象：前向展开"]
    F --> G
    H["EKF：根据预测历史构造原有 Actor 观测"] --> G
    D --> I["预测终点的长期价值"]
    G --> I
    I --> J["短期 BPTT：回报梯度经模型传回 Actor"]
    G --> R["短期累计奖励"]
    R --> J
    J --> B
    D --> B
    C --> K["真实完成结果更新 SGS"]
    K --> A
~~~

推荐主方案有五个组成部分：

1. 保留 SGS 产生真实训练经验，保持任务成功统计的真实来源。
2. 学习包含机器人—物体交互的共享高层世界模型。
3. 保留真实 PPO 的策略与价值学习，用已有 EKF 观测服务于 Actor。
4. 从真实经验中的可信起点进行短期想象，结合末端价值，通过 BPTT 辅助改进连续动作。
5. 用真实执行评价改进是否有效，并持续修正模型、价值和使用范围。

世界模型主要是训练期工具。本方案不要求部署时每一步执行模型规划，也不把 MPC 作为默认组成部分。训练侧可使用仿真真值和物理参数，但这些信息不因此自动成为 Actor 的额外输入。

## 5. 数据从哪里来，三种采样如何分工

世界模型数据来自当前教师在 Isaac Gym 中实际执行的轨迹。SGS bank 提供起点，Actor 提供动作，仿真器提供状态变化。静态初态本身不能替代状态转移数据。

一条经验至少表达“处于什么状态、实际执行了什么动作、随后变成什么状态”；还需要知道与转移有关的环境条件、动作持续时间和回合边界。奖励及任务结果用于训练价值和检验模型。

初期可以直接使用正在训练的 PPO 产生数据，也可以让已有策略在仿真中重新采样。无需等到教师完全训练成功，也无需先采集实机专家示范。SuperMimic 的参考动作库服务于跟踪目标；本任务的目标由抓取奖励和成功规则定义，世界模型数据来自实际交互。

成功和失败经验都需要保留。夹空、推偏、短暂抬升后掉落，以及稳定保持，分别描述不同的动作后果。仅保存成功轨迹，会削弱模型区分成败边界的能力。

需要明确区分三种采样分布：

| 分布 | 选择什么 | 主要目标 |
|---|---|---|
| 真实重置分布 | 下一回合从哪个 SGS 配置开始 | 推动策略访问具有学习价值的状态 |
| 模型拟合分布 | 已有经验中的哪些连续片段用于学习动力学 | 覆盖不同阶段、接触结果和物理条件 |
| 想象起点分布 | 哪些真实轨迹状态适合开展模型辅助训练 | 在模型及价值仍可信的范围内改进策略 |

真实重置与想象起点不必相同。想象可以从回合中途的真实状态开始；但这个起点应包含对应的控制记忆和任务进度，不能把静态姿态当作完整中间状态。

模型拟合既要关注近期策略访问的区域，也要保留部分历史接触与保持经验。数据片段不能跨越回合重置。旧策略的转移仍可用于学习同一受控系统的动力学；如果低层控制或物理条件变化，则必须区分对应条件。

SGS 的成功率只由真实完成的回合更新。想象成功、模型预测成功和辅助分类概率，都不进入 SGS 的真实成功历史。

## 6. 世界模型学习什么系统、预测什么状态

模型学习的对象是一个高层动作执行后的等效闭环：

$$
\hat x_{t+1}=F_\omega(x_t,a_t,\xi_t,\Delta t_t).
$$

这里的闭环包括高层命令、冻结低层控制、机械臂控制以及机器人与物体的物理交互。它不需要在研究起点重新训练一个独立的底层运动控制器。

符号含义如下：

- $x_t$：物理状态、必要控制记忆、任务进度及观测历史组成的状态表示，允许其中一部分由历史隐状态表达。
- $a_t$：当前9维连续高层动作；第6号索引为 `[0,1]` 夹爪开度，其余8维保留末端与底盘动作语义。
- $\xi_t$：影响动力学的条件，如摩擦、质量、执行器特性及外部运动条件。
- $\Delta t_t$：本次高层动作的实际持续时间，与回合级固定物理参数分开处理。

**可解释输出优先围绕以下四组物理量。**

| 对象 | 核心预测内容 | 主要用途 |
|---|---|---|
| 底盘 | 运动增量、姿态、线速度和角速度，保留高度及重力方向信息 | 接近、转向、稳定性和跌倒风险 |
| 末端 | 实际位置、姿态，以及动态接触所需的运动速度 | 对准、拦截、触碰和抬升 |
| 夹爪 | 实际开度，必要时包括开合速度 | 区分控制命令与接触后的实际状态 |
| 物体 | 位置、姿态、线速度和角速度 | 运动跟随、接触偏移、抓持、滑移和掉落 |

选择局部、统一的坐标表达，减少无关全局平移的影响，同时保留底盘移动及参考系变化。姿态预测应遵守旋转几何；位置和姿态的残差不是同一种加法。

由这些状态派生并重点检验：

- 物体—末端相对位置和相对姿态；
- 物体—末端相对线速度和角速度；
- 物体相对当前台面的抬升高度；
- 底盘对目标的相对位置，以及机器人稳定性。

这些关系不必全部独立预测。由同一组基本物理状态计算，可以减少相互矛盾。评价也不能只看所有维度平均后的误差：少量物体相对位姿误差，可能比大量无关关节维度的微小误差更影响抓取。

**紧凑输出不等于充分状态。** 相同底盘、末端和物体瞬时状态，可能对应不同腿部构型、步态、累积末端目标或低层历史。推荐研究“紧凑物理输出＋必要历史隐状态”；如果这种表达无法支持连续预测，则补充更完整的关节及控制状态。

另一种候选是显式预测底盘与全部关节位置、速度，再通过运动学得到末端状态。即使采用这种表达，仍需处理带历史的低层控制器，不能宣称仅有刚体与关节状态就已经充分。

状态表达必须满足一个闭环要求：预测后能够继续构造下一步 Actor 观测、Critic 输入、奖励和终止条件。只预测几项任务指标，可以做辅助分析，但不足以据此宣称已经得到可递归训练策略的世界模型。

已知台面运动、控制目标更新、保持计数、历史最高抬升和历史最近距离，可以按已有规则推进。它们可能需要进入状态，但不必全部作为神经网络自由回归的输出。

接触、滑移和失抓概率可以作为辅助任务，但需要独立可信的标签。当前抓取代理不能直接充当真实接触标签。初版不要求显式预测所有接触点的力，先验证物理运动与事件后果是否足够准确。

## 7. EKF 与世界模型如何配合

EKF 回答“目标沿已有运动趋势会到哪里”；世界模型回答“执行机器人动作之后，机器人和目标会怎样变化”。两者可以共存。

主方案保留当前 Actor 的 EKF 观测。一个值得单独验证的模型结构，是把 EKF 作为目标运动先验，让动作条件模型学习对该先验的修正。以位置为例：

$$
\hat p^{obj}_{t+1}
=\hat p^{EKF}_{t+1}
+\Delta p_\omega(x_t,a_t,\xi_t,\Delta t_t).
$$

这里表示所需预测时刻的运动先验，不要求把现有固定预测时域原样当作一步转移。姿态需要相应的旋转组合，不能照搬位置相加。

修正项同时包含运动外推误差和交互影响，不能把它全部解释为机器人接触的因果效应。接触前，先验可能较有用；接触后，模型应能够充分修正它，描述物体被带动、滑移或脱手。

这一结构是否比直接预测物体转移更好，需要单独比较。若先验在接触转换时持续误导模型，就应减弱其影响，而不是强迫物体遵守接触前轨迹。

连续想象时，应由预测轨迹及已有历史构造因果一致的观测。不能使用仿真中的真实未来，也不能在所有想象步重复使用起点的一次 EKF 预报。用于策略梯度的观测映射和历史更新，需要支持所声称的梯度路径；任何近似或梯度截断，都应明确其含义并验证影响。

模型监督使用仿真物理真值，不以 EKF 预测充当真值。模型可以看训练侧真值，Actor 则继续使用所定义的可用观测，避免不知不觉改变策略的信息条件。

## 8. 世界模型如何学习

模型从真实轨迹中的一个起点开始，沿实际记录的动作连续预测若干步，用预测结果与真实后续状态比较。后一步使用前一步预测的状态，从而检验误差是否会在闭环中累积。

概念上的学习目标为：

$$
\mathcal L_{\mathrm{WM}}
=\sum_{j=1}^{K}
\left(
\lambda_s\ell_{\mathrm{physical}}(\hat s_{t+j},s_{t+j})
+\lambda_r\ell_{\mathrm{relative}}(\hat s_{t+j},s_{t+j})
+\lambda_e\ell_{\mathrm{event}}(\hat e_{t+j},e_{t+j})
\right).
$$

物理误差覆盖机器人与物体状态，相对关系误差强调抓取所需的几何和运动关系，事件误差只用于存在可信标签的辅助任务。各组量纲与重要性需要分别考虑；这些权重不是原文已经为 DQ 确定的参数。

奖励、观测和终止中能够根据状态及规则计算的部分，尽量保持与原任务一致；需要学习的部分则分别检验。不能因为状态平均误差小，就默认奖励和终止预测也正确。

物理随机化尽可能作为条件输入，已知观测噪声与物理转移分开处理。对未观测扰动，允许模型保留不确定性，不把它们全部解释为可被确定预测的规律。高误差可能来自缺少数据，也可能来自不可消除的随机性，两者对采样决策的意义不同。

想象也应尽量保持与真实训练一致的随机过程：回合级物理参数在同一条轨迹内保持一致，逐步随机动作时长按实际过程处理；如果基线存在观测噪声或延迟，则从预测物理状态构造观测时保留对应条件。没有启用的扰动不额外假定存在。世界模型无需预测噪声本身，但不能让真实 Critic 对应有扰动的任务，而让想象 Actor 始终处于理想化环境。训练侧知道的条件也不因此成为 Actor 可用信息。

学习窗口与想象窗口应分别选择。一个模型在真实动作序列上预测良好，不保证在当前 Actor 自行选择动作的闭环轨迹上同样可靠；两种预测都需要检查。

多步世界模型拟合本身也可以沿预测序列反向传播，但它以预测误差为目标、更新模型参数。第 10 节的策略 BPTT 则以想象回报为目标、更新 Actor 参数。仅完成前一种学习，并不意味着已经采用 SuperMimic 的核心策略优化方式。

## 9. 长期价值从哪里获得

推荐保留现有 PPO 从真实仿真经验学习价值的原则。其含义是：从当前信息出发，按照当前策略继续执行，预计得到多少折扣任务回报。

$$
V_{\mathrm{real}}^\pi(v_t)
=\mathbb E_\pi
\left[\sum_{k\geq0}\gamma^k r_{t+k+1}\mid v_t\right].
$$

$v_t$ 表示价值函数实际使用的信息。基线兼容方案中，它是现有 Critic 的观测；只有明确增加训练侧状态时，才能把它解释为更完整的状态输入。

该价值包含接近、抬升、保持及各类惩罚，不等于最终成功概率，也不等于最优策略可以达到的潜力。策略和价值需要共同学习；缺少成功经验时，Critic 不会凭空知道尚未发现的成功路径。

PPO 通过真实奖励与 bootstrap 构造 λ-return／GAE 对应的价值目标。每段数据不必执行到最终成功，后续收益可以随更新逐渐向前传播。SGS 有机会让保持附近的真实成功更早出现，改善这部分学习，但不能保证传播必然有效。

现有 Actor 与 Critic 使用相同观测，且入口移除了部分速度信息。因此主方案有一个明确限制：复用其价值学习，不代表现有输入已充分区分所有抓持状态。

首先采用基线兼容的 $V_{\mathrm{real}}(\hat o)$，由预测物理状态及因果历史构造对应观测。若发现相同观测下的保持进度、速度或控制记忆差异显著影响后续结果，再单独研究训练侧增强的 $V_{\mathrm{priv}}(x)$。后者仍用真实回报学习，属于新增方法，需设置无世界模型的独立对照。

真实价值用于模型终点时，任务奖励、折扣、奖励尺度与终止语义必须一致。网络内部是否采用归一化，不改变尾值应表达相同回报单位的要求。

如果需要明确预测最终成功概率，可另定义：

$$
U^\pi(x)=P_\pi(\text{在任务规定的回合内完成连续保持}\mid x).
$$

它可以由真实回合结果学习，但不作为主方案的必要组成，也不直接替代原值函数。以成功概率替换累计回报，会改变优化目标，必须另行说明。

## 10. 通过短期 BPTT 直接改进策略

### 10.1 短期想象的优化目标

从真实轨迹中选取起点，在模型内让当前策略闭环产生短期动作。策略评价包括预测窗口内的奖励，以及预测终点之后的真实任务价值：

$$
\hat J_H
=\mathbb E\left[
\sum_{k=0}^{H-1}\gamma^k\hat c_k\hat r_{k+1}
+\gamma^H\hat c_H V_{\mathrm{real}}(\hat v_H)
\right],
\qquad
\hat c_0=1,\quad
\hat c_{k+1}=\hat c_k(1-\hat d_{k+1}).
$$

$\hat d$ 表示预测终止概率，$\hat c$ 是后续回报仍有效的权重。即时奖励乘 $\hat c_k$，而不是下一步的存活权重：结束动作获得的成功奖励需要保留，终止后的未来回报才消失。

成功、失败和超时应有明确语义。若时间上限属于任务目标，剩余时间会影响价值；若只是采样截断，是否 bootstrap 应与原算法一致。不能把成功终止一律当作负面“死亡”，也不能统一把各种截断混成失败。

策略改进的含义是：比较动作对短期机器人—物体状态的影响，并通过末端价值考虑后续保持。一次快速但即将滑落的抬升，不应仅凭即时奖励就胜过能够完成后续保持的动作。

### 10.2 BPTT 如何把未来回报传回当前策略

先从真实经验取出起点 $\hat x_0=x_t$，在一个短窗口内重复“构造观测—策略产生动作—模型推进状态”：

$$
\hat o_k=O(\hat x_k),\qquad
\hat a_k=T\!\left(\mu_\theta(\hat o_k)\right),\qquad
\hat x_{k+1}=F_\omega(\hat x_k,\hat a_k,\xi_k,\Delta t_k).
$$

映射 $T$ 仅将第6号索引的 latent 均值变为 sigmoid 开度，其他8维不变。真实执行用 $q=q_{closed}+opening(q_{open}-q_{closed})$ 形成夹爪关节目标。每步的全部9维动作都由当前预测观测重新计算，夹爪不使用固定参考序列，也没有夹爪 `detach()`。

BPTT 不叠加动作采样噪声；真实 PPO 则先从 latent Gaussian 采样，再作相同的动作映射。这里 `sigmoid(μ6)` 是确定性均值命令，不等于随机开度的期望。必要历史已包含在 $x$ 中，$O$ 由预测状态及历史构造观测。起点、物理条件和逐步采样的动作时长在一次展开内作为给定条件，所有均值动作路径保留梯度。

前向过程沿时间展开：

~~~text
Actor 参数 θ
  → 当前连续动作均值 u₀
  → 世界模型预测状态 x₁
  → 下一步观测 o₁ 与连续动作均值 u₁
  → 后续预测状态……
  → 窗口内奖励与末端价值
~~~

然后从总回报开始，沿这条计算链反向传播，得到模型辅助策略梯度：

$$
g_{\mathrm{BPTT}}=\nabla_\theta\hat J_H.
$$

例如，想象轨迹末端显示物体相对夹爪的运动更稳定，长期价值更高，BPTT 就利用模型的导数，把“这种改进与之前哪些动作变化有关”的信号传回 Actor。

**闭环中的每一步都重新调用当前策略。** 梯度既包含动作直接改变下一状态的影响，也包含前序状态改变后续观测、进而改变后续动作的影响。同一组 Actor 参数在多个时刻使用，所有时刻的贡献共同形成更新方向。因此不能把未来动作视为与前序状态无关的固定输出。

这一过程直接更新产生动作的策略参数。若仅让模型给出预测，然后仍只用 PPO 的优势估计更新 Actor，就没有使用这里定义的模型路径梯度。

### 10.3 三条学习路径，以及参数冻结的含义

| 学习路径 | 目标和数据 | 本路径更新的参数 |
|---|---|---|
| 世界模型多步拟合 | 真实轨迹上的预测误差 | 世界模型参数 $\omega$ |
| 真实 PPO 训练 | 真实奖励、优势估计与价值目标 | Actor 均值参数 $\theta$、标准差参数 $\phi$ 和 Critic 参数 $\psi$ |
| 策略 BPTT | 均值动作轨迹的短期想象回报与末端价值 | Actor 均值参数 $\theta$；标准差 $\phi$ 不更新 |

这里将 Actor 的均值网络记为 $\theta$，状态无关的 `log_std` 记为 $\phi$。标准差仍是 PPO 的可学习参数，但不参与 BPTT 动作生成，也不在辅助步中更新。

策略 BPTT 中，世界模型与 Critic 的参数固定，但以下导数仍需保留：

- 世界模型输出对输入状态、连续动作的导数；
- 预测状态到后续 Actor 观测及必要历史的导数；
- 可微奖励与终止代理对预测状态的导数；
- 末端 Critic 输出对其输入的导数。

**固定 Critic 参数，不等于把末端价值当作常数。** 仍需允许“动作改变终点状态，终点状态改变长期价值”的梯度传回前面的动作。若切断这条输入梯度，就失去了末端价值对终点状态的直接改进信号。

真实仿真器与起点之前的历史不参与这次反向传播，起点经验作为给定条件。窗口内的连续预测状态则应保持所定义的梯度连接；若每步都切断，后面的回报无法通过动力学链影响更早的动作。

世界模型和 Critic 在各自学习阶段仍分别通过真实转移与真实回报更新。Actor 的 BPTT 更新不会通过改变模型或评价器参数来抬高本次想象分数。

### 10.4 BPTT 与 PPO 如何共同作用

概念上的 Actor 目标是：

$$
\max_\theta\quad
J_{\mathrm{PPO}}^{\mathrm{real}}(\theta)
+\beta\,
\mathbb E_{x\sim q_{\mathrm{imag}}}
\left[w(x)\hat J_H(\theta;x)\right].
$$

$w$ 控制是否以及多大程度信任模型，$\beta$ 控制辅助更新强度。这是混合方案的概念表达，不表示额外项自动获得 PPO clipping 的约束，也不声称它是真实任务回报的无偏梯度。

将起点分布、采样条件和可信度权重视为本次更新的给定条件时，策略梯度可概念性地写为：

$$
g_\theta
=g_{\mathrm{PPO}}^{\mathrm{real}}
+\beta\,\mathbb E_{x\sim q_{\mathrm{imag}}}
\left[w(x)g_{\mathrm{BPTT}}(x)\right].
$$

PPO 利用真实执行结果提供学习信号，BPTT 利用模型中的动作后果导数提供补充信号。二者可以共同服务于同一个教师；保留 PPO 与引入 BPTT 并不冲突。上式只概括均值参数的两种学习来源；标准差 $\phi$ 仅由 PPO 优化。当前实现先进行真实 PPO 更新，再用独立 Adam 提议均值 BPTT 更新，并通过全9维 Gaussian KL 决定接受或完整回滚；这并不等价于对上述概念联合目标做一次反向传播。

原版 SuperMimic 主要通过模型 BPTT 更新 Actor；本方案采用“真实 PPO＋模型 BPTT”，属于需要独立验证的混合方法。BPTT 的梯度对所定义的可微代理目标成立，并不保证是实际接触任务的正确改进方向。

### 10.5 为什么使用短期 BPTT

不需要沿整个抓取回合反向传播到最终保持成功。模型只在可信的短窗口内展开，窗口之外的后续回报由 Critic 概括，并通过末端价值对输入的梯度影响窗口内动作。

这种短窗口相当于给时间反传设置边界：起点以前的经验固定，窗口内部保持所需梯度，终点之后由价值估计承接。它与在每一个预测步都切断状态梯度不同。

窗口过长会增加模型误差累积，也可能放大或削弱梯度；窗口过短则更依赖 Critic 对后续结果的判断。选择应依据真实动作效果验证和物理时间，而不是照搬原文 32 步，或要求窗口必须覆盖完整的 10 步保持。

短期 BPTT 并不自动解决模型偏差：预测状态、动作影响和末端价值的输入梯度仍需共同验证。真实经验训练出的 Critic，也可能在不可信的预测状态上给出错误方向。

### 10.6 连续夹爪、动作变换与不可微规则

**当前夹爪是连续控制变量。** teacher 环境使用 `continuous_opening_v1`，第6号索引开度从0闭合到1张开，按关节上下限插值。世界模型收到相同的连续开度，动作历史和变化惩罚也使用开度，不再使用符号编码。BPTT 可沿 `μ6→sigmoid→opening→后续状态／回报` 优化夹爪，同时继续优化其余8维。

真实 PPO 保留随机探索，全部9维标准差只由 PPO 更新。策略概率在 latent Gaussian 基础上计入夹爪逆 logit 和 Jacobian，避免用未变换的高斯密度错误评价开度动作。辅助 BPTT 的目标是确定性均值轨迹回报，不是随机 PPO 策略期望回报的无偏梯度；真实 Critic 在预测轨迹上的适用性仍须检验。

当前 KL 使用完整9维 latent Gaussian。相同可逆 sigmoid 在精确实数下保留 KL；执行限幅和数值端点保护仍需区分。PPO 的裁剪目标不会自动保护额外模型更新，所以保留辅助步的 KL 拒绝和完整回滚。

连续开度不消除接触非光滑性，也不把成功标签变成连续量。原闭爪意图判断已同步为 `opening<0.5`，仍只是抬升／保持成功和可选 `stop_pick` 所用的代理，而非夹持力或实际接触判据。实际夹爪运动受物体接触约束，不会强制达到目标开度。

旧二值动作模型与新开度模型的动作含义不同；应重新采集转移并训练模型、验证9维动作效果，不能直接沿用旧8维探针放行。SGS bank 保存的实际关节位置／目标语义不变，可以继续用于初态。

## 11. 模型可信度与课程如何配合

模型可靠性至少包含三个层面：

| 层面 | 要验证的问题 |
|---|---|
| 状态预测 | 能否连续预测物体、末端、底盘以及关键相对运动？ |
| 事件预测 | 能否区分稳定抬升、滑移、失抓和失败？ |
| 动作效果 | 模型认为更好的动作，在真实仿真中是否确实改善短程结果？ |

事件诊断可以来自预测物理轨迹和已有任务规则，不要求额外增加独立事件预测头。使用当前抓取与保持规则时，应称为任务代理事件；只有具有可信独立标签，才能声称验证了真实接触或滑移分类。辅助事件头与标签体系仍是可选设计。

低 MSE 或多个模型相互一致，都不能保证动作导数正确。尤其在接触边界，模型可能准确拟合常见状态，却错误预测动作变化的影响。

应在可恢复的一致起点和条件下，对动作施加不同方向、不同有限幅度的扰动，比较模型预测与真实执行的收益变化。接触处不一定存在稳定的经典导数，因此实际动作改进效果比形式上的梯度连续更重要。

可信度决定想象起点、窗口和模型辅助强度。若预测即将进入不可信区域，应在最后仍可信的状态接价值，而不是先进入错误状态后依赖 Critic 补救。Critic 自身也要有足够的数据支持。

可信度是训练选择依据，不应变成 Actor 可以主动操纵的额外奖励。否则策略可能追求“模型容易预测”的行为，而非完成抓取。

真实采样与模型使用应区别对待：

| 区域特点 | 真实仿真 | 模型辅助 |
|---|---|---|
| 策略处于学习边界，模型可靠 | 继续重点练习 | 可以使用 |
| 策略处于学习边界，模型不可靠 | 收集有价值的新经验 | 降低使用强度或暂缓 |
| 已掌握的重要技能 | 保留必要覆盖与复习 | 在验证范围内复用 |

不能直接用模型可信度过滤真实 SGS 难例。越难预测的关键接触区域，可能越需要实际练习。

主方案先保留原 SGS。后续可研究在真实采样中适度补充“模型尚未掌握、但有望从新数据学会”的配置；这属于新的课程机制，不能只以原始预测误差越大越好来定义。

## 12. 历史复习作为独立增强

SuperMimic 的重置采样包含 50% 均匀、40% 当前低回报优先和 10% 历史困难复习。它偏向低回报，与当前 SGS 的中间成功率优先不同。

可研究以下概念性混合：

$$
q_{\mathrm{reset}}
=(1-\alpha-\beta)q_{\mathrm{SGS}}
+\alpha q_{\mathrm{coverage}}
+\beta q_{\mathrm{history}}.
$$

其中覆盖分布保留对完整任务和各类初态的练习，历史分布保留过去困难、刚学会或开始退化的配置。比例需要实验选择，不照搬原文。

当前 SGS 已保留非零采样概率，额外历史记忆的价值必须通过遗忘与完整任务结果证明。不同 family 的初始距离和奖励机会不同，不能直接用未校准的累计回报统一排序。

重置复习影响策略练习；历史转移复用影响世界模型记忆。两者可以分别启用和消融，也不等同于 TSIL 的轨迹自模仿。

## 13. 一个完整的学习循环

整个方法可以持续在线运行，不要求先把教师或模型单独训练到完美。

1. SGS 选择真实回合起点，当前策略在 Isaac Gym 中执行。
2. 真实回合结果更新 SGS；真实奖励和轨迹用于 PPO 的策略与价值学习。
3. 将真实交互片段用于世界模型学习，兼顾接近、接触、抬升、保持和失抓。
4. 检查近期策略分布下的多步预测、事件预测和动作效果可信度。
5. 从可信的真实轨迹状态开展短期想象，用原任务奖励和真实价值评价结果。
6. 固定世界模型与 Critic 参数，通过短期 BPTT 将想象回报梯度传回 Actor，对连续动作施加受约束的辅助更新，再回到真实仿真采集和评估。
7. 根据真实结果调整模型使用范围；模型暂不可靠时，真实 PPO 仍能继续学习。

在最初阶段，世界模型可以先观察和学习，不立即影响 Actor。启用依据是动作效果验证，而不是固定训练了多少轮，也不是必须等到任务已完全学会。

这种顺序的研究意义是可归因：能够区分“模型是否可学”与“学到的模型是否有助于策略”，而不会把二者失败混在一起。

## 14. 如何验证这套思路

### 14.1 三个主要假设

| 假设 | 应观察到的证据 | 不足以支持它的现象 |
|---|---|---|
| SGS 改善关键交互模型学习 | 相同数据预算下，关键接触阶段覆盖和预测质量改善 | 仅平均状态误差降低 |
| 可靠模型能改善动作方向 | 模型建议在真实仿真中提高短程结果，减少失抓或不稳定 | 仅想象奖励提高 |
| 短期模型与长期价值能改善完整任务 | 相同评价规则下，完整起点的保持成功率与学习效率改善 | 只在 near_goal 重置上成功率提高 |

### 14.2 建议的实验关系

| 对照 | 主要问题 |
|---|---|
| SGS＋EKF＋PPO 基线 | 当前方法的真实学习曲线是什么？ |
| 基线＋只学习、不参与策略更新的模型 | 世界模型是否能学好？额外成本是多少？ |
| 基线＋可信短期模型 BPTT 辅助 | 动力学路径梯度是否带来真实任务增益？ |
| 模型辅助中移除末端价值 | 长期价值是否帮助把局部收益转化为后续保持？ |
| 相同模型下比较不同可靠性控制 | 是否减少错误动作建议和策略退化？ |
| 相同初态池的均匀采样与 SGS，分别有／无模型辅助 | SGS 与模型是否互补，而不只是各自独立有效？ |
| 有／无 EKF 运动先验的模型 | 运动先验是否帮助动态目标预测，是否在接触后产生偏差？ |
| 单独增加历史复习或训练侧 Critic 信息 | 增益是否来自这些独立变化？ |

不必同时开展所有实验。先验证模型，再验证 BPTT 辅助更新，最后展开课程和结构消融。“模型只学习、不更新策略”的对照需要明确切断模型对 Actor 的回报梯度，否则不能作为无策略 BPTT 的对照。若以后比较 PPO-WM 与模型 BPTT，应使用可比的模型和数据，以区分“快速预测”与“使用动作梯度”的贡献。

比较采样对模型数据质量的影响时，可使用相同固定策略或匹配的策略阶段，避免把策略本身变强误认为单纯的数据覆盖收益。端到端实验再评价共同学习的总效果。

### 14.3 评价指标

主要指标使用固定完整任务起点分布与原有保持成功标准，包括真实成功率、达到给定成功率所需的真实交互量，以及包含模型训练和想象在内的总计算成本。分别做真实样本预算和计算预算匹配，报告多个独立种子的结果。

模型诊断按执行阶段统计物体位姿、相对运动、机器人稳定性、多步误差和事件预测，不仅按 SGS family 汇总。另保留未参与模型拟合的配置或轨迹，检查对新状态的有效性；这不自动代表能泛化到未见物体。

策略诊断可以包括接触后抬升率、抬升后保持率、失抓率和机器人失败率，但这些是解释指标，不能替代完整任务成功率。

当前成功规则本身是代理条件。若新增独立的物理抓持诊断，应同时报告原任务成功率与诊断结果，而不悄悄更改成功定义来比较新旧方法。

训练回报受 SGS 分布变化影响，不能单独作为方法有效的证据。模型产生的轨迹也不能用于计算真实成功率。

## 15. 何时说明思路成立，何时需要调整

| 观察结果 | 更合理的解释与下一步研究 |
|---|---|
| 单步准确，多步很快偏离 | 状态记忆、闭环覆盖或预测时域不足；先解决模型表达 |
| 状态误差较小，但动作建议无效 | 动作影响或局部梯度不可信；不能仅扩大想象训练 |
| 想象收益增加，真实成功下降 | 模型或 Critic 被离分布预测利用；缩小使用范围并重新验证 |
| near_goal 提升，完整任务不提升 | 初态技能未连接到完整过程，或重置状态与正常可达状态存在差异 |
| 加入真实价值后仍偏好短暂抬升 | 检查奖励与最终任务一致性、价值输入和后续保持经验 |
| 成功率改善但总时间增加 | 可能改善样本效率，却未改善计算效率，应分别报告 |
| 先验模型在接触后持续变差 | EKF 运动先验约束过强，或交互修正不足 |

当前最值得争取的研究结论是：**课程产生的关键接触经验，可以转化为可靠的动作后果预测，并进一步改善真实完整任务的学习。**

原文的加速倍数、训练动作零失败，以及平地人形动作展示，都不能直接作为动态抓取的预期结果。也不能仅凭方法组合就宣称具有新的研究贡献；贡献需要由上述可检验机制和结果支持。

## 16. 范围与后续增强

推荐先固定主线：SGS＋EKF＋真实 PPO、共享高层交互模型、真实回报 Critic，以及面向可信连续动作的短期 BPTT。这里 BPTT 是主方案的策略更新机制；以下方向在主线得到支持后再分别研究：

- 将 EKF 运动先验结构与直接动力学预测进行比较。
- 让真实课程兼顾策略能力前沿与模型的可学习知识缺口。
- 增加历史困难配置复习，检查策略与模型遗忘。
- 给 Critic 增加训练侧真实状态，或增加明确的成功概率预测。
- 研究连续夹爪开度／接触过程的模型误差，以及更可靠的开合时机优化。
- 最后再比较纯 SuperMimic 式更新、TSIL 组合或实机数据修正。

其中，切换 MuJoCo Warp 不是采用该思想的前提。实机数据也不是启动模型学习的必要条件；它属于后续修正仿真与现实交互差异的方向。
