# 教师策略训练改进思路（暂不考虑 sim-to-real）

> 2026-11-20。对象：[`train_teacher_sgs_ekf.sh`](../DQ_high-level/train_teacher_sgs_ekf.sh) 训练的 sugar_box 教师（skrl PPO + SGS 配置库 + EKF 未来位姿，Level02）。
> 目标只有一个：**在仿真里把教师训得更好、更快。** sim-to-real 见 [`直接部署教师_改进思路.md`](直接部署教师_改进思路.md)。
> 保留一条约束：Actor 观测仍然只用真机可以得到的量；特权信息只进 critic、奖励、课程或辅助监督。
> 下文的收益都是**待验证的假设**。本机只有短程冒烟训练的日志，没有完整的训练曲线，所以第 1 节的证据来自 checkpoint 和代码，不来自训练曲线。

## 0. 一页结论

旧文档（git HEAD 中的 `TODO_list.md` 等）已经覆盖了“任务和方法”层面的创新，例如拦截裕度、τ、SGS 在线演化、时空 token、CaT、有色噪声、镜像和 SAPG。本文**不重复**这些内容，而是从更底层的“PPO 能不能学好”入手。

读了现有 checkpoint 以后，发现了三处会**同时拖累所有方法**的实现层问题：

1. **动作几乎全部饱和**（§1.1）。末端位移的有效范围是 ±0.02 m，但策略的原始输出标准差约为 2，策略噪声 σ 约为 0.19。按正态近似，只有约 1% 的样本落在线性区。机械臂和底座实际上是 bang-bang 控制。
2. **抓取候选的 RPY 发生角度回绕**（§1.2）。90 维 RPY 中有 38 维方差大于 1.5，最大 3.97；平滑小角度变化的方差应该在 0.1–0.3 左右。
3. **奖励不满足马尔可夫性**（§1.3）。`approaching` 和 `lifting` 依赖历史最小距离和历史最大高度，`pick_up` 依赖保持计数，这些量 critic 都看不到。另外，`command_reward` 在训练到一半时突然打开。

**推荐顺序：**

| 优先级 | 编号 | 做什么 | 成本 | 依据 |
|---|---|---|---|---|
| ★★★ | **T1** | 动作参数化：按物理范围缩放，初始 std 约 0.5，确定性评估与训练一致 | 低 | Andrychowicz et al. 2021；CAPG；Beta policy |
| ★★★ | **T2** | 价值学习：critic 补上隐藏的奖励状态；消融价值裁剪；去掉中途的奖励切换 | 低 | Ng et al. 1999；Pardo et al. 2018；Andrychowicz et al. 2021 |
| ★★★ | **T3** | 旋转表示：RPY 改为 6D；GFM 输出改为嵌入 | 中 | Zhou et al. 2019 |
| ★★☆ | **G1** | 特权脚本专家：初态多样化、JSRL 式引导、TGRL 式自适应 BC | 中 | JSRL、TGRL、DemoStart、OmniReset |
| ★★☆ | **T4** | 网络：残差加 LayerNorm（SimBa）、更大的 critic，并防止可塑性下降 | 中 | SimBa、BRO、Juliani & Ash 2024 |
| ★☆☆ | **A1** | 多目标梯度冲突（GCR-PPO），或者种群训练（DexPBT） | 中–高 | GCR-PPO、DexPBT |
| ★☆☆ | **A2** | 换成大规模并行的离策略算法（FastTD3 / FastSAC / FlashSAC） | 高 | FastTD3、FlashSAC |

**T1–T3 会改变基线**，应该先做，再去比较旧文档里的主线方向。否则主线方向的增益会和实现层问题混在一起，结论不可靠。

## 1. 证据：从 checkpoint 和代码里读到的事实

checkpoint 是 [`DQ_high-level/DQ_teacher/agent_75000.pt`](../DQ_high-level/DQ_teacher/agent_75000.pt)。观测宽度 1284，与当前 SGS + EKF 配置一致（1024 特征 + 58 状态 + 13 未来位姿 + 180 抓取 + 9 动作），但文件本身不能确认它来自哪一次运行。读取方法是在没有 torch 的环境里直接解析 zip 中的 pickle 和张量数据。

### 1.1 动作饱和

环境对网络的原始输出 `a` 直接做物理截断（[`b1z1_base.py:2095`](../DQ_high-level/envs/b1z1_base.py#L2095) 之后）：位置 `clip(a, ±0.02)`，姿态 `clip(a, ±0.06)`，夹爪 `clamp(±1)`，前进速度 `clip(±0.45)`，偏航角速度 `clip(±0.6)`。`clipActions` 没有设置，等于无穷大。策略是均值无界、std 与状态无关的高斯分布，初始 `log_std = 0`，即 std = 1。

下表的“原始动作”统计来自观测归一化器对 `last_action` 通道的统计（这个通道存的是**未截断**的采样动作）；“饱和比例”是按正态近似估计的、落在截断区的样本比例。

| 维度 | 有效范围 | 策略 σ = exp(log_std) | 原始动作均值 / 标准差 | 饱和比例（估计） |
|---|---|---|---|---|
| 末端 Δx, Δy, Δz | ±0.02 m | 0.19, 0.20, 0.19 | (−0.33, 0.48, 0.94) / (2.24, 1.33, 2.31) | ≈ 99% |
| 末端 Δroll, Δpitch, Δyaw | ±0.06 rad | 0.42, 0.12, 0.23 | (0.16, 0.08, −0.13) / (1.76, 0.83, 1.22) | 94–97% |
| 夹爪 | ±1 | 0.23 | −1.29 / 2.06 | ≈ 69% |
| 底座 vx | ±0.45 m/s | 0.055 | −0.70 / 1.51 | ≈ 79% |
| 底座 ωz | ±0.6 rad/s | 0.031 | −0.03 / 0.60 | ≈ 32% |

**后果：**

- **梯度信号弱。** 均值已经远离截断边界时，再改变它不会改变环境行为，PPO 只能靠噪声偶尔越过边界获得学习信号。CAPG（Fujita & Maeda, ICML 2018）和 Beta policy（Chou et al., ICML 2017）讨论的正是“有界动作配高斯策略”的偏差和方差问题。
- **精细对准困难。** 末端每步的位移几乎只能取 ±2 cm，靠符号翻转来对准抓取点。
- **KL 自适应学习率失真。** 对原始输出计算的 KL 在饱和区间不反映行为的变化。
- **观测和惩罚失真。** `last_action` 观测和 `action_rate` 惩罚（[`reward_vec_task.py:107`](../DQ_high-level/envs/reward_vec_task.py#L107)）用的都是未截断的原始值，没有物理意义。

### 1.2 角度回绕

观测归一化器的方差显示：抓取候选的 90 维 RPY 中，有 38 维方差大于 1.5，主要是 yaw，最大为 3.97。作为对照，物体 RPY 的方差为 0.20、0.08、0.14，末端 RPY 的方差为 0.13、0.09、0.05。

在 [−π, π] 上均匀分布的方差是 π²/3 ≈ 3.29。方差达到 2–4，只能是数值在 ±π 附近来回跳变。也就是说，同一个抓取位姿在相邻两步可能被编码成相差约 2π 的两个数。GFM 的 Key / Value 线性层看到的是不连续的输入；输出层又把注意力加权后的结果直接投影成 6 维 RPY（[`predictattention.py:53`](../DQ_high-level/modules/predictattention.py#L53)），再拼进 MLP。

### 1.3 奖励的马尔可夫性和非平稳性

| 奖励项 | 依赖的隐藏量 | critic 能否看到 |
|---|---|---|
| `approaching`：`tanh(10·max(0, closest − curr))`（[`reward_vec_task.py:11`](../DQ_high-level/envs/reward_vec_task.py#L11)） | `closest_dist`，历史最小距离 | 否 |
| `lifting`：同样的写法 | `highest_object`，历史最大高度 | 否 |
| `pick_up`（50）、`grasp_base_height` | `pick_counter` / `pick_hold_progress`，保持计数 | 否 |
| `command_reward` | `global_step_counter ≥ total_timesteps/2` 才打开（[`reward_vec_task.py:67`](../DQ_high-level/envs/reward_vec_task.py#L67)） | 否；而且是整个训练过程中的一次阶跃 |

同样的观测，回报的期望可能完全不同：末端退回后再接近，只有超过历史最小距离才会有奖励。critic 只能对这些隐藏量取平均，优势估计的方差因此变大。方向 0（critic 时间通道）解决的是同一类问题中“剩余时间”这一项，这里还剩几项没有补上。

### 1.4 其他实现事实

- PPO 配置：`entropy_loss_scale = 0`（skrl 默认值）；`value_clip = 0.2` 且 `clip_predicted_values = True`；`lambda = 0.95`；KL 自适应学习率阈值 0.008；24 步 rollout，5 个 epoch，6 个 minibatch（[`train_multistate_DQ_teacher.py:439`](../DQ_high-level/train_multistate_DQ_teacher.py#L439)）。
- 网络：Actor 和 Critic 各有一套独立的特征编码器和 GFM，主干是 512-256-128 的 ELU MLP，没有归一化层。
- 现有的 `--use_tanh` 不能直接拿来解决 §1.1：训练时采样的是 TanhNormal，但确定性评估返回的是 **tanh 之前**的均值（[`gaussian.py`](../third_party/skrl/skrl/models/torch/gaussian.py) 的 `act`），而环境端只乘 0.02、不截断（[`b1z1_base.py:2096`](../DQ_high-level/envs/b1z1_base.py#L2096)）。评估时的动作会超出训练时的范围。

## 2. 第一组：PPO 实现层修正（便宜，最先做）

### T1 动作参数化

**依据。** Andrychowicz et al.（ICLR 2021）在大规模实验中发现，策略初始化最好满足三点：均值接近 0、标准差较小（约 0.5）、与观测无关。动作要么做 tanh 压缩，要么截断到范围之内。CAPG 和 Beta policy 说明，有界动作配无界高斯策略会带来梯度偏差，并增大方差。

**做法：**

```python
# 网络输出 a ∈ R^9；环境中统一先截断到 [-1, 1]，再乘物理尺度
scale = [0.02]*3 + [0.06]*3 + [1.0] + [0.45, 0.6]
u = a.clamp(-1, 1) * scale            # Δpos, Δorn, gripper, vx, ωz
# 策略：log_std 初始化为 log(0.5)（也可以按维度设定），max_log_std 设为 0
```

帮我做另外把动作的末端 Δx, Δy, Δz 的限幅改成±0.05m
为什么要# 网络输出 a ∈ R^9；环境中统一先截断到 [-1, 1]，再乘物理尺度

策略网络的输出是什么?它经过怎样的处理后交给低层策略执行

几个配套修改：

- `last_action` 观测和 `action_rate` 惩罚都改用截断后的 `a.clamp(-1, 1)`；
- 确定性评估直接用均值，环境截断以后与训练一致；
- `lifted_grasp_mask` 用到了 `actions[:, 6]`（[`b1z1_pickmulti.py:954`](../DQ_high-level/envs/b1z1_pickmulti.py#L954)），夹爪原本就是 ±1 的语义，不受影响；
- `small_value_set_zero` 的死区作用在缩放后的指令上，语义也不变。

**进阶。**

- 把夹爪改成 Beta 分布或者二值（Bernoulli）动作，因为它本质上是开 / 合两种状态；
- 或者对位置和姿态分别采用 tanh-squash，并修好 `--use_tanh` 路径中确定性评估的不一致。

**要盯的指标：**

- 每一维的饱和比例（新增日志）；
- 末端轨迹的平滑度（相邻高层动作的 L1 差）；
- 抓取阶段末端到抓取点误差的分布；
- full_task 的成功率和成功用时。

**风险。** 动作语义改变，需要新的实验目录从头训练。旧的奖励权重是在 bang-bang 行为下调出来的，可能需要重新调 `acc_penalty`、`action_rate`。

### T2 价值学习

1. **补全马尔可夫状态（最便宜）。** 把 `closest_dist`、`curr_dist − closest_dist`、`highest_object − curr_height`、`pick_counter / hold_steps`、`lifted_object` 这 5–6 维只交给 critic，做法与 `critic_time_obs` 相同（Policy 端切掉）。这不改变策略的目标，只让价值函数可以学得准确。Pardo et al.（ICML 2018）对时间限制的论证同样适用：价值依赖的变量必须出现在 critic 的输入里。
2. **（消融）改为势函数塑形。** 把“破纪录式”的接近奖励换成 `F = γΦ(s′) − Φ(s)`，`Φ = −κ·d(ee, obj)`；`lifting` 同理。Ng et al.（ICML 1999）证明势函数塑形不改变最优策略。对运动物体，`d` 会因为物体自己移动而变化，这在势函数框架下仍然成立。这和旧文档里“拦截势函数”的接口一致，可以作为它的简化版和对照组。
3. **价值裁剪。** Andrychowicz et al. 2021 的建议是不用 PPO 式的价值裁剪；TSIL 审查文档也记录过“价值归一化 + 价值裁剪”导致 critic 零梯度的反例。建议在基线上做一组 `clip_predicted_values = False` 的消融；同时试 λ = 0.9（同一篇论文的推荐值）。
4. **去掉中途切换的奖励。** `command_reward` 从第一步起就以小权重生效，或者在前 20% 的训练里线性升到目标值，避免第 60k 步时价值函数受到冲击。这也是旧文档“方向 5 CaT”要处理的对象之一，二者可以合并。
5. **价值诊断。** 新增 explained variance 日志，即 `1 − Var(R − V)/Var(R)`。如果它长期很低，说明 critic 是瓶颈，应该优先做 1 和 T4。

### T3 旋转表示

**依据。** Zhou et al.（CVPR 2019）证明 Euler 角和四元数对神经网络是不连续的表示，5D / 6D 表示是连续的，并且在多个任务上表现更好。

**做法：**

- 抓取候选（30 × 6 → 30 × 9：位置 3 维 + 旋转矩阵前两列 6 维）、物体姿态、末端姿态、EE 目标姿态和 EKF 未来位姿，全部改用 6D 表示；
- GFM 的 Key / Value 输入改为 9 维；输出不再投影成 6 维 RPY，而是直接输出 d_model 维嵌入拼进 MLP。DeViGrasp 的教师也聚合的是投影后的抓取特征，而不是位姿平均；
- 动作端的 Δroll / Δpitch / Δyaw 可以保留，因为增量很小，不会回绕。

**验收。** 对比改前改后归一化器统计的方差，抓取候选通道的方差应该降到 0.3 以下；同时看注意力熵、相邻两步 argmax 候选的切换率和成功率。

### T4 网络与优化（中等成本）

- **残差 + LayerNorm 主干。** SimBa（ICLR 2025）用观测归一化、残差前馈块和后置 LayerNorm 引入“简单性偏置”，论文报告它能和 PPO 等多种算法结合，并在 Craftax 上提升了 PPO。BRO（NeurIPS 2024）发现，配上强正则化以后，**扩大 critic** 收益最明显。建议先只把 critic 换成 SimBa 块，并加宽到 1024；Actor 保持不变，方便归因。
- **可塑性。** 一次训练约 5000 次 PPO 更新、15 万次梯度步，而 SGS 让训练分布持续变化。Juliani & Ash（NeurIPS 2024）发现，在分布变化下，on-policy 训练中可塑性下降普遍存在；正则化类方法（L2、shrink+perturb、regenerative regularization）能缓解它，其中 soft shrink+perturb 的泛化表现最好，而且可以和 LayerNorm 结合。先加“休眠神经元比例”的日志，确认确实存在问题再处理。
- **SimbaV2**（ICML 2025）改用超球面归一化，用于离策略方法；如果做 A2，可以一起考虑。

## 3. 第二组：引导与课程（中等成本，可能收益最大）

### G1 特权脚本专家

**为什么有效。** 本任务的结构很清楚：底座跟随并拦截，机械臂按抓取候选靠近，然后闭合、抬升、保持。用仿真真值（物体未来位姿、候选抓取）加 IK 写一个**脚本专家**并不难。它不需要很强，成功率有 30–50% 就能提供有价值的引导。专家使用的特权信息只存在于训练中，**Actor 的观测不变**。

**四种用法，按成本从低到高：**

| 用法 | 做法 | 依据 |
|---|---|---|
| (a) 体检 | 专家的成功率是任务可解性的参考上界；它的失败模式可以帮助判断是奖励的问题还是动力学的问题 | — |
| (b) 初态多样化 | 在专家轨迹上的随机时刻拍快照，作为 SGS 的新配置族，覆盖接近、跟随、预抓取等**中间状态**，弥补现有 4 个配置族的缺口 | DemoStart（本地 [`Demostart.pdf`](papers/Demostart.pdf)）、OmniReset（本地 [`Omnireset.pdf`](papers/Omnireset.pdf)）的多样化重置 |
| (c) 先引导后探索 | 每个回合的前 `h` 步由专家执行，之后交给策略；`h` 随训练逐步缩短到 0 | JSRL（Uchendu et al., ICML 2023）：有好的引导策略时，样本复杂度从关于视野的指数级降到多项式级 |
| (d) 自适应 BC 辅助损失 | 在 PPO 损失上加 `λ·‖π(o) − a_expert‖²`，`λ` 由 TGRL 的规则自动调节：另训一个只用奖励的辅助策略，主策略表现更好时增大 `λ`，反之减小，以免陷入“模仿差距” | TGRL（Shenfeld et al., ICML 2023） |

**建议先做 (a) 和 (b)。** 它们不改变 PPO 损失，和现有 SGS 无缝衔接。(c) 要改 rollout 逻辑；(d) 要再训一个辅助策略，放到最后。

**和 TSIL 的关系。** TSIL 挖掘的是策略自己的高效成功轨迹；专家轨迹能在训练早期策略还没有成功轨迹时提供起点，二者可以叠加。

### G2 SGS 侧的补充（只列旧文档没有的部分）

- **配置族的覆盖。** 现有 4 个配置族中，full_task、pregrasp、at_grasp、near_goal 都是“起点”或“终点附近”，缺少“正在跟随运动物体、距离 0.5–1.0 m”这类中段状态。G1(b) 或旧文档方向 3(a)（从失败回合自生成初态）都能补上。OmniReset 的结论是，重置分布的多样性本身就是大规模 RL 学会难任务的关键。
- 旧文档已经覆盖了贝叶斯先验、ACCEL 式变异和均匀混合，这里不重复。

### G3（选做）种群训练

DexPBT（RSS 2023）在 Isaac Gym 上用去中心化的种群训练，同时演化超参数和奖励权重，在手臂加灵巧手的任务上明显优于常规的端到端训练。本任务有 11 个奖励项，权重是人工调的，适合交给 PBT。单卡上可以把 8192 个环境分成 4–8 个子种群，这和旧文档里的 SAPG（X1）是同一类工程，可以合并实现。

## 4. 第三组：算法层（大改动，选做）

### A1 多目标梯度冲突：GCR-PPO

本地 [`GCRPPO.pdf`](papers/GCRPPO.pdf) 用多头 critic 把 Actor 的更新拆成按目标计算的梯度，再按目标优先级消解冲突（任务奖励优先于正则项）。论文报告平均提升 9.5%，冲突越大的任务提升越多。

本任务可以分成三组目标：

- 任务：`approaching`、`lifting`、`pick_up`、`grasp_base_height`；
- 姿态：`ee_orn`、`base_approaching`；
- 正则：`acc_penalty`、`action_rate`、`limit_yaw_rotation_penalty`、`command_reward`。

它和旧文档的“多头 critic”（X2）重叠。**先在 T2 上统计各组优势之间的相关性**：只有负相关明显时才值得做。

### A2 大规模并行的离策略算法

- **为什么考虑。** 本任务每个高层步要跑 28–32 个物理步，外加 7–8 次低层策略推理，**采样很贵**。PPO 每批 19.7 万个样本只训 5 个 epoch，样本复用率低。离策略方法可以用回放缓冲区反复利用样本。
- **候选：**
  - FastTD3（2025）：并行仿真、大批量更新、分布式 critic，在 IsaacLab 等环境上加速训练；
  - FlashSAC（RSS 2026）：通过约束权重、特征和梯度的范数来稳定离策略学习，报告在 60 多个任务上优于 PPO，高维操作任务的增益最大。
- **代价：**
  - TSIL 和 KL 自适应学习率这一套都绑定在 PPO 上；
  - Q 网络需要输入动作，GFM 要放进 critic；
  - SGS 与算法无关，可以直接复用。

  建议在 T1–T3 稳定之后，作为独立的分支试验。

## 6. 实施顺序和实验设计

| 步 | 内容 | 判定 |
|---|---|---|
| **0 诊断** | 在现有基线上加日志：每维动作饱和比例、价值 explained variance、各配置族成功率、成功用时、注意力熵；跑 3 个种子作为基线 B2 | 确认 §1 的现象在当前配置下仍然存在 |
| **1 T1** | 只改动作参数化 | 成功率和用时，看饱和比例是否降到 10% 以下 |
| **2 T2** | critic 补隐藏状态，去掉奖励切换；另做价值裁剪和 λ 的消融 | explained variance 和成功率 |
| **3 T3** | 6D 表示 + GFM 嵌入 | 方差、注意力切换率、成功率 |
| **4 G1** | 先写专家，得到 (a) 的体检结果，再做 (b) 的 SGS 新配置族 | 专家成功率；加入新配置族后 full_task 的学习曲线 |
| **5 T4 / A1** | 按诊断结果挑选：critic 是瓶颈就做 T4，奖励冲突明显就做 A1 | — |
| **6 旧主线** | 在新基线上推进拦截裕度等方向 | 按旧文档的关卡执行 |

**评估口径**（沿用旧文档）：

- 至少 3 个种子，确定性动作；
- 主指标只看 full_task 配置族，成功必须完成 `hold_steps` 的保持；
- 在相同训练步数的快照上比较；
- 每一步只改一个变量，并使用新的实验目录。

## 7. 风险

| 风险 | 说明 |
|---|---|
| T1 以后奖励权重失衡 | 原权重是在 bang-bang 行为下调的；先只看 `pick_up` 成功率，必要时重调正则项 |
| T2.2 的势函数在运动物体下噪声大 | 物体移动会让 `d` 变化；保留 T2.1 的做法作为主方案，T2.2 只作消融 |
| T3 改动面大 | 涉及环境、GFM、Value 和 checkpoint 格式；建议分两步：先改抓取候选的表示，再改其他姿态 |
| G1 的专家写不好 | 成功率低也有用：(b) 只需要专家轨迹覆盖中段状态，不要求它成功 |
| A2 工程量大 | 先确认 PPO 在 T1–T3 之后是否仍然样本受限 |
