# 用 SGS 改进教师策略：最小初版

> 2026-10-20。依据本地 [SGS.pdf](SGS.pdf) 重新设计。本文是待实现方案，未运行 SGS 实验。

## 1. 先抓住 SGS 的核心

**准备一批可重复使用的任务配置，根据每个配置最近的成功率，动态决定下一回合从哪里开始。**

论文 §3.2 的关键是这个持续运行的闭环：

~~~text
从配置 i 开始回合
→ 当前策略尝试完成任务
→ 记录本回合成功或失败
→ 更新配置 i 的近期成功率
→ 更常抽到当前“有时成功、有时失败”的配置
~~~

成功率很高的配置可能已经掌握，很低的配置可能暂时学不会；中等成功率是论文采用的“值得练习”的代理信号。简单和困难配置仍保留非零概率，随着策略变化，它们也可能重新成为重点。这里没有预先规定“先练抓持，再练抓取，最后练接近”的训练顺序。

多样初态提供练习范围，SGS 决定练习次数；初态覆盖是采样器发挥作用的前提。论文 B.3 在 rod-in-hole 实验中移除 Near-Goal 后未能学会任务，但这不意味着本任务必须照搬其三类初态。SGS 自身不会生成新的可解状态，也不能在所有配置都失败时凭空产生成功。

上一版方案把大量篇幅放在初态分类和工程配套上，淡化了上述闭环。本初版只验证一个问题：**相同的初态池、相同的 PPO 和训练预算，按近期成功率采样，是否比均匀采样更有利于原始完整任务？**

## 2. 初版只准备两类初态

沿用 `sugar_box`、当前教师网络与奖励、`--no_velocity_obs`、5000 个环境和 Level02 运动设置。

| 初态来源 | 具体状态 | 提供的练习机会 |
|---|---|---|
| 原始起步 | 机器人距物体 2 m，物体在桌上，机械臂恢复默认姿态 | 完整的接近、抓取、抬升和保持 |
| 临近抓取 | 底座处于可抓取位置；物体仍在桌上；夹爪张开，末端位于可行抓取姿态前约 5–10 cm | 最后对准、跟踪、闭合、抬升和保持 |

临近抓取先从一个经过验证的候选抓取姿态出发，再加小幅位姿扰动，不要求一次覆盖全部候选抓取。5–10 cm 指沿抓取接近方向的末端偏移，是待仿真验证的范围。底座位置与机械臂姿态一起确定，保证可达、无初始穿透，并同步设置控制目标。

两类都使用原来的台面高度和运动范围，不同时降低运动速度。两类都要求完成原来的最终任务：抬升满足现有几何判据，并连续保持 15 个高层步。

**两类配置从训练开始就同时可采样。** 初版暂不加入“已抓住、待抬升”，是为了减少接触状态构造的工作量，并不预设临近抓取一定足够容易。如果这些配置长期全失败，就需要补充能产生终局成功的更容易初态，例如已夹持、相对桌面初始位置抬高 3–8 cm 但未达成功高度的状态；此时应先解决初态覆盖，再重新做对照。

### 什么算一个“配置”

初版预生成并保存 **1024 个配置，两类各 512 个**。这个规模是工程起点，论文操作实验使用的是 32768 个。

每个配置有固定 `config_id`，对应一组具体的机器人/物体初态和台面运动参数。临近抓取配置还包含机械臂、夹爪及相容的控制目标。不能只记录“临近抓取”这个类别，也不能每次抽到同一 ID 又任意重新生成它的姿态。

现有物理随机化及 `rand_control` 可继续保留；估计的是这些扰动下，该名义配置的成功概率，不要求每次轨迹完全一致。

两类各占一半是配置池的构成，**不是训练期间固定各分一半回合**。SGS 后续直接在全部 1024 个配置上抽样，自然改变两类实际获得的练习量。

## 3. 采样器只做三件事

**第一，按具体配置记结果。** 每个配置保存最近 `H=100` 个已结束回合的布尔结果，成功率是有效历史的均值。复用已修复的 `episode_success`，每个完成回合只记一次。

不能只算两类初态各自的平均成功率。例如，同一类中一半配置总成功、另一半总失败，类别平均虽然是 50%，却掩盖了配置之间的差异。

**第二，把成功率转换为采样概率。** 初版沿用论文操作任务参数 `t=0.5、κ=1、T=2、ε=1e-4`，因此可以直接写成：

~~~python
p = mean(valid_history)       # 每个配置分别计算
w = (p + eps)**0.5 * (1 - p + eps)**0.5
q = softmax(log(clamp_min(w, eps) + eps) / 2)
~~~

其中权重下限来自论文 B.2。该规则使中间成功率的配置获得较大权重，同时保留两端概率；它不是只选择成功率最接近 50% 的一个配置。

空历史暂用 `p=0.5` 计算采样概率，日志标记为“未观测”；有结果后只平均真实记录，不把未填充位置算作失败。这是初版的初始化约定，不是论文明确给出的要求。开局所有配置权重相同，自然均匀采样，无须额外规定一个人工课程阶段。

**第三，在 reset 时抽下一回合的配置。**

~~~text
读取旧 config_id 和 episode_success
→ 将结果写入旧配置的历史
→ 更新采样概率
→ 有放回抽取新 config_id
→ 应用新初态，开始下一回合
~~~

首次初始化不提交结果；主动中断的回合不伪记失败。多个环境同时结束且使用同一配置时，所有结果都要写入，不能因重复索引相互覆盖。5000 个环境共享 1024 个配置是允许的。

PPO 继续使用新采集的轨迹正常更新。这里重采样的是回合起点，不是回放历史成功轨迹，也不需要按 SGS 概率给 PPO loss 另加权重。

## 4. 最少改动在哪里

| 位置 | 初版工作 |
|---|---|
| 新增一个 `utils/sgs.py` | 保存/读取配置池，维护成功历史，提供 uniform/SGS 两种抽样方式 |
| [b1z1_pickmulti.py](../DQ_high-level/envs/b1z1_pickmulti.py) 与 [b1z1_base.py](../DQ_high-level/envs/b1z1_base.py) | 构造并应用临近抓取初态；reset 清状态前提交旧结果，再选择新配置 |
| [教师训练入口](../DQ_high-level/train_multistate_DQ_teacher.py) | 选择配置池及 uniform/SGS 模式，记录简单诊断日志 |
| [奖励与成功判定](../DQ_high-level/envs/reward_vec_task.py) | 训练复用已有保持成功标签；评估增加同样的保持标准，避免现有 eval 抬起即终止 |

环境接入尤其要处理两点：

1. 新初态必须在原有随机重置之后、写入模拟器之前应用，防止被默认位置和关节姿态覆盖。
2. 实际关节状态、末端/夹爪控制目标与首帧观测保持一致；新回合的 `pick_counter` 和成功标记清零。

先用少量环境验证重复 reset，确认没有穿透、默认目标回拉或异常立即终止。uniform 和 SGS 共用这条重置路径。

初版按从头训练做对照。完整断点续训系统、时序网络、特权 Critic 和学生蒸馏留到确认有效之后。

## 5. 只做一组必要对照

| 实验 | 配置池 | 下一回合如何选 |
|---|---|---|
| Uniform | 同一份 1024 个配置 | 等概率抽样 |
| SGS | 同一份 1024 个配置 | 按上述近期成功率权重抽样 |

先用相同训练种子做一对探索性试验，网络、奖励、环境数和交互预算保持一致。初版沿用用户 `--timesteps 120000` 的总计划；如果提前观察或停止，不改这个参数，因为当前奖励时序使用了 `args.timesteps/2`。单次试验用于判断是否值得继续，收益确认再增加训练种子。

只保留三组核心结果：

- **原始 2 m 起步的保持成功率**：主要判断依据。另采一份相同的测试配置给两种方法使用，不从训练池复制；使用独立评估环境和相同步数的模型快照，确定性动作，不更新策略或采样器，并完整统计预定评估回合。
- **各类初态的成功率和实际抽样比例**：解释训练机会如何变化，不能代替完整任务成绩。
- **配置近期成功率的分布**：检查是否出现可区分的成功率，还是几乎全部为 0；未观测配置单独显示。

评估必须与训练一样要求保持 15 步。当前 `self.eval=True` 会在抬起后提前结束，不能直接拿旧评估值作主结果。

若 SGS 优于同池 Uniform，才支持自适应采样有效。若两者相近，初版没有证明 SGS 带来额外收益。若全失败，先补容易初态；若辅助初态学会但 2 m 任务没改善，则尚未完成技能迁移，不能把辅助成功率上涨算作目标达成。

## 6. 实施顺序

1. 构造少量临近抓取初态，验证它们能够正确、稳定地重置。
2. 固定两类配置池，接入“回合结果 → 近期成功率 → 下一次 reset 抽样”的闭环。
3. 在同一配置池上跑 Uniform 与 SGS，对比原始完整任务的结果，再决定是否扩充初态。

这是代码落地顺序。实际训练时，两类初态同时开放，练习重点随成功率自动变化。

论文依据：§3.2（第 4–5 页，SGS 闭环）、§5（第 9 页，SGS 不构造初态）、A.2（第 14 页，配置池）、B.2–B.3（第 16–17 页，采样细节与初态覆盖消融）。
