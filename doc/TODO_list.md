## 0. 主线一句话

> 预测物体会去哪（EKF），预测自己多快能到（τ），二者合成**拦截裕度** `M = max_{i,h} [h − τ(s, g_i(t+h))]`。裕度同时决定三件事：策略看到什么（表征），奖励什么（塑形），在哪里练（课程）。

论文由三个环节组成，对应三组实验：

| 环节 | 实验组 | 内容 |
|---|---|---|
| 奖励 | Ours-R | 用拦截势函数替换追踪式接近奖励 |
| 课程 | Ours-RC | 在 Ours-R 上加入贝叶斯 SGS，配置库在线演化 |
| 表征 | Ours | 在 Ours-RC 上加入带裕度特征的时空抓取 token |

三个环节要用 2³ 析因消融证明它们是一个整体。

## 4. 阶段 2：τ 和裕度（离线），以及 D2–D4

先用现有 checkpoint 的 rollout 离线训练 τ。诊断通过后，再接到在线训练里。

- [ ] **2.1 环境导出。** 每步在 `extras` 中放入这些量：机器人根状态、臂基位姿、末端位姿、末端目标，以及分开的终止原因。它们环境里都已经算出来了，只是没有导出。
- [ ] **2.2 解析的物体未来。** 把 [`utils/sgs_motion.py`](../DQ_high-level/utils/sgs_motion.py) 里的瞬时速度扩展成“`t+h` 时刻的位姿”：对台面的恒定 body twist 积分，物体随台面运动（[`b1z1_base.py:1811`](../DQ_high-level/envs/b1z1_base.py#L1811)）。接触或抬起后用掩码关闭。
- [ ] **2.3 轨迹缓冲。** 每个环境维护整个回合的数据（最多 100 步，约 40 维；8192 个环境约 130 MB）。回合结束后生成事后标注样本：
  - 样本是“t 时刻的状态 → t+k 时刻末端实际到达的位置（表达在 t 时刻冻结的臂基坐标系 Ā_t 中）”，标签是实际耗时；
  - 高层步长在 0.14–0.16 s 之间随机，所以标签按实际时间戳计算，不用 `k × 常数`。
- [ ] **2.4 τ 网络。**
  - **输入**：[`low_obs_history_buf`](../DQ_high-level/envs/b1z1_base.py#L387)、当前末端目标、目标位置 `g`。
  - **训练**：只学位置部分，用偏下的 expectile 回归（q ≈ 0.1）逼近下包络。
  - **兜底**：`τ = max(τ_learned, τ_floor)`。物理下界 `τ_floor` 由底座最大速度 0.45 m/s 和手臂工作空间给出。
  - **姿态部分用解析下界**：`τ_orn = max_axis |Δrpy| / 0.06` 步，最终 `τ = max(τ_pos, τ_orn)`。
  - **工程**：独立优化器，EMA 目标网络，单独注册 checkpoint。
  - **第二版**：换成 QRL。
- [ ] **2.5 裕度计算。** 第一版只对物体中心计算：16 个时刻，从 0.3 s 到 4.8 s，每 0.3 s 一个；同时要求 `h ≤ T_max − t`（剩余时间）。输出 `M(t)`、`h*(t)`，并记录每步的计算开销。
- [ ] **2.6 D2：τ 的质量。** 包括留出数据上的误差和校准曲线，并与两个基线比较：只用物理下界，以及按指令积分。
- [ ] **2.7 D3：`M₀` 的预测力（关卡）。** 对 1536 个配置计算初态裕度 `M₀`，看它对配置成功率的 AUC；再拟合 `p ≈ σ((M₀ − b)/T)`，检验命题 P4。
  - **不通过**：先改进 τ；仍然不行就放弃课程环节。
- [ ] **2.8 D4：失败构成。** 记录每个回合的 `M(t)`，按下面三类统计比例，同时记录不可挽回点 `t_loss`。

  | 类型 | 判据 |
  |---|---|
  | F1 一直来不及 | `max M < 0` |
  | F2 裕度丢失 | `M` 曾 ≥ 0，接触前降到 < 0 |
  | F3 到了没抓住 | 到达时 `M ≥ 0`，但抓取、抬升或保持失败 |

  比例决定后面先做哪个环节：F1 多就先做课程；F2 多就先做奖励和表征；F3 多说明瓶颈不在本文。

## 5. 阶段 3：奖励环节（Ours-R，最干净的单变量实验）

- [ ] **3.1 实现 `_reward_intercept_potential`。**
  - 位置：[`reward_vec_task.py`](../DQ_high-level/envs/reward_vec_task.py)。
  - 公式：`Φ = κ·clip(M, −c, c)/c`，`F = γΦ(s') − Φ(s)`，其中 `γ` 取 PPO 的折扣因子。
  - 物体抬起后关闭。
  - 环境需要持有 τ 的引用，在环境创建后注入。
  - 奖励用特权的解析未来（2.2），不进策略观测。
- [ ] **3.2 两组对照。**

  - 两组都要重新调 `κ`，并检查它和 `lifting`、`pick_up` 的相对尺度。
- [ ] **3.3 塑形对照。**

## 6. 阶段 4：课程环节（Ours-RC）

- [ ] **4.1 贝叶斯 SGS。** 改动在 [`utils/sgs.py`](../DQ_high-level/utils/sgs.py)：
  - `success_rates()` 改为后验均值 `p̂ = (成功次数 + n₀·p₀) / (总次数 + n₀)`，先验 `p₀(c) = σ((M₀(c) − b)/T)`；
  - 这替换了 `p_init = 0` 的约定（[`DQ_teacher.yaml:35`](../DQ_high-level/data/cfg/DQ_teacher.yaml#L35)）；
  - 采样核 `p̂^0.5 (1−p̂)^0.5`、ε 下限和温度都不变。
- [ ] **4.2 `M₀` 的刷新和标定。** 每隔若干次迭代，对全部配置重算 `M₀`；`b`、`T` 用最近回合的 `(M₀, 成败)` 做逻辑回归拟合。
- [ ] **4.3 标记不可行配置。** `M₀` 明显小于 0 的配置标为不可行：降权，单独统计，不当作“难题”反复练习。
- [ ] **4.4 方向 3(a)：从失败回合自生成初态。**
  - 回合进行中在随机步拍快照，保存的字段和 `_reset_sgs_envs` 写回的字段相同；
  - 回合失败后，把快照写进新的 `self_play` 类（512 槽的环形缓冲）；
  - 快照时物体正处于被推挤接触中的，丢弃；
  - 这一类使用独立的 ID 区间，并限制总采样比例。主指标仍然只统计 full_task。
- [ ] **4.5 方向 3(b)：变异前沿配置（ACCEL 式）。**
  - 对成功率处于中间段的配置做小扰动：台面更快、底座更远、朝向更偏；
  - 先用 `M₀ ∈ [0, δ]` 筛选，再用 [`sgs_bank_builder.py`](../DQ_high-level/utils/sgs_bank_builder.py) 在小批量上做物理验证；
  - 替换已掌握的配置（历史满且成功率 > 0.95）和不可行配置；
  - 替换时清空对应的 SGS 历史和 TSIL 目标。
- [ ] **4.6 余量 δ 的课程。** 让 `δ` 随训练逐渐变小，从“宽裕”练到“刚好来得及”。
- [ ] **4.7 课程对照。** 均匀采样、原 SGS、PLR / SFL、BaRC 式的起点扩展。

## 7. 阶段 5：表征环节（Ours，改动最大）

`Policy` 和 `Value` 都要改 `PredictAttentionSelector`，旧 checkpoint 不兼容，需要新的实验目录。

- [ ] **5.1 G1：改表示方式。** RPY 改为 6D 旋转表示；输出改为 d_model 维嵌入，不再压成 6 维（[`predictattention.py:48`](../DQ_high-level/modules/predictattention.py#L48)）。
- [ ] **5.2 G2：时空 token。** 把 30 个候选抓取（[`b1z1_pickmulti.py:812`](../DQ_high-level/envs/b1z1_pickmulti.py#L812)）分别变换到 EKF 预测的 `h ∈ {0, 0.6, 0.9}` 时刻，共 90 个 token。
  - 每个 token 的特征：位置 3 维、6D 旋转、`h` 和 EKF valid 标志、简单可达性 2–3 维。
- [ ] **5.3 裕度特征。** 每个 token 再加 `m(i, h)`、`τ` 和“是否来得及”3 维。这里的 `g` 用 EKF 预测，不用特权真值。
- [ ] **5.4 G3：选择的时间一致性。** 两种做法任选：加“上一步是否被选中”标记位，或者对相邻两步的注意力分布加 KL 惩罚。
- [ ] **5.5 抓取后屏蔽未来 token。** 抓住或抬起物体后，屏蔽 `h > 0` 的 token。
- [ ] **5.6 EKF 升级 1（取决于 1.4 的结果）。**
  - B1：用陀螺仪把 EKF 窗口里的历史相对位姿旋转到当前臂基坐标系，再做外推；
  - B2：再补偿平移，平移来自里程计或自我前向模型的 Y1。
  - 预测的语义会变，需要新的实验目录。
- [ ] **5.7 表征诊断。** 注意力熵、相邻两步 argmax token 的切换率，以及注意力和 token 裕度的关系。
- [ ] **5.8（可选）方向 9：事后标注监督。**
  - 找到实际抓取时刻 `t*` 和实际执行的抓取 `i*`，在 `t* − h` 时刻把 token `(i*, h)` 标为正（成功回合）或负（失败回合）；
  - 用这些标签训练 token 打分头，作为辅助损失或注意力先验；
  - 失败归因里的 `t_loss` 也可以作为回标时刻。

## 14. 工程注意

- **改观测语义就从头训练。** token、EKF 坐标系或输入维度变化时，用新的实验目录从头训练。
- **τ 的数据跨度。** PPO 的 rollout 只有 24 步，τ 需要几秒的跨度，所以要用 2.3 的整回合缓冲。
- **势函数会慢慢变化。** τ 在训练中更新时，奖励和课程都用它的 EMA 目标网络；仍然不稳定，就分阶段冻结 τ。
- **评估口径不变。** 所有对照沿用第 7.6 条的口径。
- **学生端没有适配。** 方向 0 的时间通道在学生端还没处理，按约定暂不处理。
